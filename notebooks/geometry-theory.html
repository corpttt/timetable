L1. 07.09 — множества, операции, отображения

(из записей Бегалиева · лекция Антоника; дополнено примерами и пояснениями)

Зачем этот блок на геометрии: дальше появятся «пространства точек», «пространства векторов», отображения между ними. Язык множеств — общий словарь.

Множество и принадлежность

Определение. (из записей) Множество — неупорядоченная совокупность различимых элементов, выделенных по определённому признаку. Запись a ∈ A — «a принадлежит A»; a ∉ A — «не принадлежит». Пустое множество ∅ не содержит ни одного элемента; |∅| = 0. Универсум U — «большое» множество, внутри которого в данной задаче живут все рассматриваемые множества (ограничивает область рассуждений).

Своими словами. Множество — мешок объектов без порядка и без дублей: {a, b} и {b, a} — одно и то же; если a = b, то {a, b} = {a}.

Пример. A = {1, 2, 3}. Тогда 2 ∈ A, 5 ∉ A. Не-пример. «Список» (1, 2, 2) — не множество в этом смысле: порядок и повторы важны для кортежа, а не для множества.

Способы задать множество (из записей):

  1. перечислением: {a, b, c};
  2. условием: {a ∈ ℕ : a mod 3 = 0} = {3, 6, 9, …};
  3. «интуитивно» (на лекции — как рабочий приём, когда формализация не нужна сразу);
  4. через операции с уже известными множествами.

Частые обозначения (из записей): ℕ — натуральные; ℤ — целые; ℚ — рациональные; ℝ — вещественные; I = ℝ ∖ ℚ — иррациональные; ℂ — комплексные. (На курсе дальше чаще всего поле скаляров — ℝ, иногда ℂ.)

Операции и Де Морган

Определение. (из записей) Для множеств X, Y ⊆ U:

  • объединение: X ∪ Y = {a : a ∈ X или a ∈ Y};
  • пересечение: X ∩ Y = {a : a ∈ X и a ∈ Y};
  • разность: X ∖ Y = {a : a ∈ X и a ∉ Y};
  • дополнение: X̅ = {a ∈ U : a ∉ X} (иногда пишут U ∖ X);
  • симметрическая разность: X △ Y = (X ∖ Y) ∪ (Y ∖ X).

Своими словами. ∪ — «всё, что хоть где-то есть»; ∩ — «общее»; ∖ — «из первого выкинуть второе»; △ — «ровно в одном из двух».

Пример. Пусть U = {1, 2, 3, 4, 5}, A = {1, 2, 3}, B = {3, 4}. Тогда A ∪ B = {1, 2, 3, 4}, A ∩ B = {3}, A ∖ B = {1, 2}, A △ B = {1, 2, 4}, A̅ = {4, 5}. (Рис. в HTML: L-1a–d — ∪ ∩ ∖ △; L-1e — A×B; L-1f–g — отображение / не-отображение.)

Объединение, пересечение и △ коммутативны и ассоциативны (из записей).

Формулы Де Моргана (из записей):

(A ∪ B) = A̅ ∩ B̅, (A ∩ B) = A̅ ∪ B̅.

Для семейства: (⋃_{i∈I} A_i) = ⋂_{i∈I} A̅_i, (⋂_{i∈I} A_i) = ⋃_{i∈I} A̅_i.

Своими словами. «Не (A или B)» = «не A и не B». «Не (A и B)» = «не A или не B».

Пример. A = {1, 2}, B = {2, 3}, U = {1, 2, 3, 4}. (A ∪ B) = {1, 2, 3} = {4}; A̅ ∩ B̅ = {3, 4} ∩ {1, 4} = {4}. Совпало.

Декартово произведение

Определение. (из записей) A × B = {(a, b) : a ∈ A, b ∈ B} — множество всех упорядоченных пар. Кортеж (a₁, a₂, …, aₙ) — упорядоченный набор; порядок важен: (a, b) ≠ (b, a), если a ≠ b.

Своими словами. Произведение — «все комбинации: взяли по одному элементу из каждого множества и записали в ряд».

Пример. A = {1, 2}, B = {x, y}. A × B = {(1, x), (1, y), (2, x), (2, y)} — четыре пары. (Рис. L-1e.) Не-пример. {1, 2} × {1, 2} ≠ квадрат на плоскости сам по себе: это множество пар чисел; геометрическая картинка — уже интерпретация.

Подмножества и булеан

Определение. (из записей) X ⊆ Y (часто на доске ⊂), если ∀x ∈ X выполняется x ∈ Y. Собственное подмножество X ⫋ Y — если X ⊆ Y и ∃ y ∈ Y с y ∉ X. (У разных преподавателей ⊂ может означать и ⊆, и ⫋ — смотри контекст лектора.)

Свойства (из записей):

  • ∀A: ∅ ⊆ A (в том числе ∅ ⊆ ∅);
  • A = B ⟺ (A ⊆ B и B ⊆ A);
  • A ⊆ B ⇒ |A| ≤ |B| (для конечных — очевидно по смыслу).

Своими словами. Подмножество — «все элементы первого лежат во втором». Равенство множеств проверяют двумя включениями.

Пример. {1, 2} ⊆ {1, 2, 3}; {1, 2} ⫋ {1, 2, 3}. Не-пример. {1, 4} ⊈ {1, 2, 3}, потому что 4 не лежит во втором.

Определение. (из записей) Множество всех подмножеств A называют булеаном и пишут 2^A (или 𝒫(A)): 2^A = {B : B ⊆ A}. Для конечного A верно |2^A| = 2^{|A|} (на лекции доказательство не давали).

Пример. A = {1, 2, 3}. Тогда 2^A = {∅, {1}, {2}, {3}, {1, 2}, {1, 3}, {2, 3}, {1, 2, 3}} — 8 = 2³ штук.

Соответствия и отображения

Определение. (из записей) Соответствие C = (A, B, Γ), где Γ ⊆ A × B. Пишут a C b, если (a, b) ∈ Γ.

Соответствие f = (A, B, R) называют отображением (функцией) f : A → B, если ∀ a ∈ A существует ровно один b ∈ B такой, что (a, b) ∈ R (эквивалентно: если a f b и a f c, то b = c, и для каждого a такой b есть).

Обозначения: f(a) = b; область определения — A; область значений / образ множества — f(A₀) и т.п.

Образ и прообраз (из записей):

  • образ множества A₀ ⊆ A: {b ∈ B : ∃ a ∈ A₀ с f(a) = b};
  • прообраз множества B₀ ⊆ B: {a ∈ A : ∃ b ∈ B₀ с f(a) = b} = {a ∈ A : f(a) ∈ B₀}.

Своими словами. Функция — правило, которое каждому элементу из A сопоставляет один результат в B. Образ — «куда попали»; прообраз — «кто попал в выбранную цель».

Пример. f : ℝ → ℝ, f(x) = x². f({−2, 2}) = {4}; прообраз {4} — это {−2, 2}. (Рис. L-1f–g.) Не-пример соответствия-отображения. Γ = {(1, a), (1, b)} при a ≠ b — одному 1 соответствуют два значения: это не функция.

На этой же лекции (из записей) уже ввели четвёрку (V, K, +, ·) и восемь аксиом векторного пространства — их подробно разбираем в L2 (на 14.09 аксиомы повторили).

L2. 14.09 — векторные пространства

(из записей Бегалиева; доказательства следствий — из записей + дополнено развёрткой; примеры — из записей)

Аксиомы векторного пространства

Определение. (из записей) Пусть V — множество («векторы»), K — поле (чаще ℝ или ℂ), + : V × V → V, (u, v) ↦ u + v, · : K × V → V, (λ, v) ↦ λv.

Упорядоченная четвёрка (V, K, +, ·) называется векторным пространством, если выполнены аксиомы:

  1. ∀ u, v ∈ V: u + v = v + u (коммутативность сложения);
  2. ∀ u, v, w ∈ V: (u + v) + w = u + (v + w) (ассоциативность);
  3. ∃ 0̃ ∈ V: ∀ u ∈ V: u + 0̃ = u (нулевой вектор; на доске часто пишут просто 0 — не путать со скаляром 0 ∈ K);
  4. ∀ u ∈ V ∃ (−u) ∈ V: u + (−u) = 0̃ (противоположный);
  5. ∀ λ ∈ K ∀ u, v ∈ V: λ(u + v) = λu + λv;
  6. ∀ λ, μ ∈ K ∀ u ∈ V: (λ + μ)u = λu + μu;
  7. ∃ 1 ∈ K: ∀ u ∈ V: 1 · u = u;
  8. ∀ λ, μ ∈ K ∀ u ∈ V: (λμ)u = λ(μu).

Своими словами. Векторы можно складывать между собой и растягивать числами из поля, и эти две операции ведут себя «как привычные стрелки на плоскости»: сложение коммутативно и ассоциативно, есть ноль и «минус вектор», растяжение распределяется по сумме.

Замечание. (из записей) Аксиомы 1–4 — это аксиомы абелевой (коммутативной) группы по сложению.

Пример. V = ℝ², K = ℝ: (x₁, y₁) + (x₂, y₂) = (x₁+x₂, y₁+y₂), λ(x, y) = (λx, λy). Нуль — (0, 0); −(x, y) = (−x, −y). Это «школьные» векторы на плоскости в координатах. (Рис. L-2c — стрелки из начала; L-2a–b — сумма и растяжение.)

Не-пример. Множество точек окружности со «сложением» как обычные векторы из начала координат: сумма двух точек окружности часто не лежит на окружности — замкнутость не выполняется, это не подпространство ℝ².

Полную проверку всех восьми аксиом для каждого примера на лекции часто оставляли упражнением; ниже — следствия и типичные примеры без восьми однотипных проверок подряд.

Следствия аксиом

(формулировки — из записей; ниже — 2 развёрнутых доказательства как образец, остальные — утверждения)

На лекции нулевой вектор обозначали 0̃ (чтобы не путать со скаляром 0).

Утверждение 1. Нулевой вектор единственен: ∃! 0̃ ∈ V.

Доказательство (образец). (из записей, развёрнуто) Пусть 0̃ и 0̃′ — два нуля. Тогда 0̃ = 0̃ + 0̃′ (потому что 0̃′ — ноль) = 0̃′ + 0̃ (коммутативность) = 0̃′ (потому что 0̃ — ноль). Значит 0̃ = 0̃′. ∎

Утверждение 2. Для каждого v ∈ V противоположный −v единственен.

Доказательство (образец). (из записей, развёрнуто) Пусть v + v̄ = 0̃ и v + v̄′ = 0̃. Тогда v̄ = v̄ + 0̃ = v̄ + (v + v̄′) = (v̄ + v) + v̄′ = 0̃ + v̄′ = v̄′. ∎

Утверждение 3. ∀ v ∈ V: 0 · v = 0̃. (доказательство на лекции: 0·v = (0+0)·v = 0·v + 0·v ⇒ после прибавления −(0·v) получаем 0̃ = 0·v.)

Утверждение 4. ∀ α ∈ K: α · 0̃ = 0̃. (упражнение на лекции; идея та же: α·0̃ = α(0̃+0̃) = α·0̃ + α·0̃.)

Утверждение 5. Если α · v = 0̃, то α = 0 или v = 0̃. (из записей: если α ≠ 0, умножаем на α⁻¹ и получаем v = 0̃.)

Утверждение 6. ∀ v ∈ V: (−1) · v = −v. (из записей: (−1)·v + v = (−1+1)·v = 0·v = 0̃ ⇒ (−1)·v — противоположный к v.)

Своими словами. Из аксиом уже следует привычное: «ноль один», «минус один», «ноль раз вектор — ноль», и произведение ноль только если ноль скаляр или ноль вектор.

Пример к следствиям. В ℝ²: 0·(3, −1) = (0, 0); (−1)·(3, −1) = (−3, 1) = −(3, −1).

Примеры векторных пространств

#### (1) ℝⁿ

Определение / конструкция. (из записей) ℝⁿ = {(x₁, …, xₙ) : xᵢ ∈ ℝ}. Сложение и умножение на α ∈ ℝ — покомпонентно. Можно думать про ℝⁿ как про множество отображений {1, …, n} → ℝ.

Своими словами. Столбец из n вещественных чисел; буква n — сколько координат у одного вектора. Складываем и растягиваем «по строчкам».

(Рис. L-2d — схема ℝ¹ / ℝ² / ℝ³; рис. L-2c — как выглядит вектор из ℝ² на плоскости.)

Пример (письменно; 3D не рисуем). В ℝ³ у вектора ровно три числа: (1, 0, 2) + (−1, 4, 0) = (0, 4, 2);   3·(1, 0, 2) = (3, 0, 6). Это та же покомпонентная арифметика, что в ℝ², только координат три.

#### (2) Пространство отображений A → V

Определение. (из записей) Пусть V — векторное пространство над K, A — любое множество. W = {f : f : A → V}. Операции: (f + g)(a) = f(a) + g(a), (λf)(a) = λ f(a).

Своими словами. «Функции со значениями в векторах» складываются так же, как значения в каждой точке.

Пример. A = {утро, вечер}, V = ℝ. Тогда f и g — просто пары чисел (значение утром и вечером); сложение — сложение пар. Это по сути ℝ².

Разжёвка. A и ℝ — разные вещи: A — где смотрим (два слота: утро / вечер), ℝ — какие числа кладём. Одно отображение f задаёт ровно два числа: f(утро) и f(вечер) — как вектор из ℝ². Складывать функции = складывать эти пары покомпонентно.

Не-пример путаницы. «A и значения — два объекта, значит не ℝ²» — нет: вектор как раз и есть набор значений по слотам A. Слотов два ⇒ ℝ².

#### (3) Геометрическое пространство V_Q из евклидова пространства

(из записей) Сами E¹ (прямая), E² (плоскость), E³ (пространство) как множества точек векторными пространствами не являются. Их «достраивают».

Почему точек мало. В векторном пространстве нужно уметь складывать элементы и растягивать скаляром. Для двух точек плоскости «A + B» само по себе не определено: куда указывает сумма? Пока нет стрелок и выбранного начала — одних точек недостаточно. Поэтому ответ на «E² — векторное пространство?» — нет.

Фиксируем точку Q ∈ Eₘ (m = 1, 2, 3). Положим V_Q := {[QX] : X ∈ Eₘ}, где [QX] — направленный отрезок (вектор) из Q в X. Ноль: [QQ]. Сложение — по правилу параллелограмма / треугольника; умножение на скаляр — растяжение/сжатие (и разворот при отрицательном α).

Своими словами. Выбрали «начало» Q и смотрим на все стрелки, начинающиеся в Q. Это уже векторы, а не «голые» точки. «Не соединены» = ещё нет стрелок — тогда векторного пространства нет.

Пример. На плоскости E² возьмём Q — начало координат. Тогда [QX] — обычный радиус-вектор точки X; V_Q выглядит как ℝ².

Коммутативность сложения видна на параллелограмме; ассоциативность на лекции 21.09 поясняли чертежом (на экзамене, по записи, могут не требовать строгого доказательства). (Рис. L-2a — сумма; L-2b — скаляр; L-2c — ℝ².)

Параллельный перенос точки вдоль вектора — биекция плоскости/пространства на себя (из записей, упражнение).

Линейные отображения и изоморфизм

Определение. (из записей) Пусть U, V — векторные пространства над одним полем K. Отображение Φ : U → V линейно, если

  1. Φ(u + v) = Φ(u) + Φ(v) (аддитивность);
  2. Φ(ku) = k Φ(u) (однородность).
Линейность
Φ(u + αv) = Φ(u) + α Φ(v)

Частая путаница. Однородность — это Φ(k u) = k · Φ(u): сначала растянули вектор u на число k, потом применили Φ — то же, что сначала Φ(u), потом растянуть картинку на то же k. Писать «(Φk)u» нельзя: Φ действует на векторы из U, а k — скаляр из поля K, не вектор. Φ к числу k не применяется.

Пример. Φ(x, y) = (2x, 2y), u = (1, 3), k = 4. Слева: Φ(4u) = Φ(4, 12) = (8, 24). Справа: 4·Φ(u) = 4·(2, 6) = (8, 24). Совпало. «(Φ·4)·u» смысла не имеет: 4 не лежит в ℝ².

Изоморфизм — биективное линейное отображение U → V. (из записей) Если Φ — изоморфизм, то Φ⁻¹ тоже изоморфизм (упражнение на лекции; идея: биекция очевидна наличием обратного; линейность обратного проверяют, применяя Φ к нужным равенствам).

Своими словами. Линейное отображение «уважает» сложение и растяжение: картинка суммы = сумма картинок. Изоморфизм — «это по сути одно и то же пространство, только назвали элементы иначе».

Пример. Φ : ℝ² → ℝ², Φ(x, y) = (2x, 2y) — линейно (растяжение в 2 раза), биективно ⇒ изоморфизм. Не-пример. Ψ(x, y) = (x², y) — не линейно: Ψ((1,0)+(1,0)) = Ψ(2,0) = (4, 0), а Ψ(1,0)+Ψ(1,0) = (1,0)+(1,0) = (2, 0).

Пример из геометрии. (из записей, идея) Пространства V_{Q₁} и V_{Q₂} в одном евклидовом пространстве изоморфны: вектор [Q₁X] переносится параллельно так, чтобы начало стало в Q₂. Обратное — перенос обратно. Это как раз «смена начала отсчёта не меняет геометрию векторов».

L3. 21.09 — аффинные пространства

(из записей Бегалиева; пояснения и примеры — дополнено)

Аксиомы аффинного пространства

Определение. (из записей) Тройка (A, V, ·), где A — множество точек, V — векторное пространство, а отображение A × A → V сопоставляет паре точек (X, Y) вектор XY ∈ V, называется аффинным пространством с ассоциированным V, если:

Аксиомы аффинного пространства
1) ∀ X ∈ A ∀ v ∈ V ∃! Y ∈ A: XY = v
2) ∀ X, Y, Z ∈ A: XY + YZ = XZ

(1) из любой точки можно единственным образом «отложить» любой вектор; (2) правило треугольника / замыкание ломаной.

Своими словами. Точки сами по себе не складываются. Но между двумя точками есть вектор «куда идти». Аксиома 1 говорит: «стоя в X и имея вектор v, ровно одна точка Y в конце стрелки». Аксиома 2: путь X→Y→Z даёт тот же суммарный вектор, что X→Z напрямую. (Рис. L-3a–b; свободные векторы — L-3c.)

Не путать. Складывать можно векторы из V (элементы XY, YZ, …). Запись «X + Y» для двух точек из A не определена: точки — не векторы. Связь точек с векторами — через «стрелку» XY или через «отложить v из X» (аксиома 1), а не через сумму точек.

Не-пример. На плоскости взять точки O и A. Имеет смысл OA (вектор) и O + OA в смысле «отложить OA из O → точка A». Не имеет смысла «O + A» как сумма двух точек.

Пример. Обычная плоскость: A = E², V = «свободные векторы плоскости», XY — направленный отрезок от X к Y (как класс / как элемент V). Это интуиция, к которой лекция идёт через фактор (ниже).

Следствия XX = 0 и −XY = YX

Следствия
XX = 0̃  −XY = YX

Утверждение. (из записей) ∀ X ∈ A: XX = 0̃.

Доказательство. (из записей, развёрнуто) По аксиоме 1 для вектора v и точки X есть единственная Y с XY = v. В частности, для v = XX существует единственная точка — это X сам. С другой стороны, XX + XX = XX (аксиома 2 при Y = Z = X). Но тогда XX + XX = XX = XX + 0̃ ⇒ (прибавив −XX) XX = 0̃. Иначе (короче, как в записи): для любого v = XY имеем v + XX = XY + XX = XY = v ⇒ XX действует как ноль ⇒ XX = 0̃. ∎

Утверждение. (из записей) ∀ X, Y ∈ A: −XY = YX.

Доказательство. XY + YX = XX = 0̃ ⇒ YX — противоположный к XY. ∎

Своими словами. «Стрелка из точки в себя — ноль». «Обратный путь — минус вектор».

Пример. На числовой прямой A = ℝ как аффинное пространство над V = ℝ: XY := Y − X. Тогда XX = 0, −(Y−X) = X−Y = YX. Подходит.

Примеры аффинных пространств

Пример 1. (из записей) Само векторное пространство как аффинное: (A, V) = (V, V), и для X, Y ∈ V полагаем XY := Y − X. Проверка аксиом сводится к свойствам вычитания в V.

Пример 2. (из записей) Евклидовы Eₙ (n = 0…3) с векторами, построенными из направленных отрезков (см. следующий блок).

Отношение эквивалентности и фактор

Зачем этот кусок на геометрии: свободный вектор — это класс равных (параллельно перенесённых) направленных отрезков.

Определение. (из записей) Бинарное отношение R ⊆ M × M: пишем x R y, если (x, y) ∈ R.

Свойства:

  1. рефлексивность: ∀ a: a R a;
  2. симметричность: a R b ⇒ b R a;
  3. транзитивность: a R b и b R c ⇒ a R c.

Определение. Отношение эквивалентности ∼ — то, у которого есть все три свойства. Класс [x]_R := {y ∈ M : x R y}.

Свойства классов (из записей):

  • классы либо совпадают, либо не пересекаются;
  • объединение всех классов = M

⇒ классы образуют разбиение M. Множество классов — фактор-множество M / R.

Своими словами. Эквивалентность — «считаем некоторых разными объектами одинаковыми». Класс — «все, кого мы склеили вместе». Фактор — «новое множество, элементами которого являются эти кучки».

Пример. На ℤ: a ∼ b ⟺ a − b чётно. Классы: «чётные» и «нечётные». Фактор — два элемента. Не-пример. Отношение a R b ⟺ a < b на ℝ: не рефлексивно (a ≮ a) — не эквивалентность.

Диагональ D = {(x, x) : x ∈ M} — отношение равенности «каждый только сам с собой»; фактор M/D биективен самому M (из записей, без подробного доказательства).

Направленные отрезки → свободные векторы

(из записей Бегалиева; идея конструкции)

В Eₙ рассматривают направленный отрезок [XY⟩. Антоник задаёт его парой (X, [XY]), где X — начало, [XY] — «прокладываемый» отрезок/вектор из начала: зная начало и вектор, знаем направление и конец.

M — множество всех направленных отрезков в Eₙ.

Отношение ∼ на M: [XY⟩ ∼ [WZ⟩, если [WZ] получается из [XY] параллельным переносом, переводящим X в W (длина и направление сохраняются).

Класс [[XY⟩]_∼ обозначают как свободный вектор XY (начало больше не важно — важны длина и направление).

V = { XY : X, Y ∈ Eₙ } — множество таких классов. Можно зафиксировать начало (удобно «нулевое») и отождествить классы с векторами вида [QX] из конструкции V_Q лекции 14.09.

Своими словами. Много стрелок на плоскости «одинаковой длины и направления, но из разных точек» — это один свободный вектор. Операции на классах задают через представителя: сложили/растянули отрезки с общим началом — получили новый класс. Линейность операций «очевидна раскрытием» (формулировка из записей). Тогда (Eₙ, V, (X,Y) ↦ XY) — аффинное пространство.

Пример. Стрелка из (0,0) в (2,1) и стрелка из (3,3) в (5,4) — один и тот же свободный вектор (2, 1): вторая получается переносом первой на (3, 3).

Дальше на курсе эту конструкцию используют как мост: «геометрические стрелки» ↔ «элементы абстрактного V». Продолжение и доказательства — лекция L4 (28.09).

L4. 28.09 — свободные векторы, ЛНЗ, базис Гамеля

(Из записей Бегалиева: Геометрия 28.09.2026.pdf; локально материалы/_архив/_бегалиев-геометрия/28.pdf. Фото доски: материалы/_архив/доска-28.09-аффинные/. Своими словами, примеры и промежуточные шаги — дополнено.)

Видео: МГУ, Тимашёв — векторные пространства: ЛНЗ и базис.

Связь с прошлым. L3 ввела аффинное пространство и классы направленных отрезков (свободные векторы). На 28.09 доводят: операции на классах корректны, V — векторное пространство, (Eₙ, V) — аффинное; затем переходят к линейной комбинации, ЛНЗ, базису (в т.ч. базису Гамеля) и к следствию про аддитивные неоднородные функции.

Операции на V и корректность

Напоминание (из записей, блок «информация с прошлой лекции»). Направленный отрезок [XY⟩ = (X, [XY]) в Eₙ, n ∈ {0, …, 3}. M = {[XY⟩ : X, Y ∈ Eₙ}. [XY⟩ ∼ [WZ⟩, если [WZ] получается параллельным переносом [XY], переводящим X в W. Свободный вектор XY := [[XY⟩]_∼. V = { XY : X, Y ∈ Eₙ }. Зафиксировав начало (удобно «нулевое»), можно отождествить классы с отрезками из одной точки: { XY : Y ∈ Eₙ }.

Определение операций на V (из записей). Берут представителей с общим началом X:

  • u + v: если u = XY, v = XZ′, то u + v := [[(X, [XY] + [XZ′])⟩]_∼;
  • λ · u: λ · XY := [[(X, λ · [XY])⟩]_∼.

То есть операции «переносят» со структуры привязанных отрезков Vₙ = {[XY] : Y ∈ Eₙ} (уже векторное пространство с лекции 14.09).

Своими словами. Чтобы сложить два свободных вектора, рисуешь оба из одной точки, складываешь стрелки как обычно, и смотришь на класс результата. Растяжение — то же.

Пример. Из точки O: u = (2, 0), v = (0, 3). Сумма — класс стрелки (2, 3). Из другой точки A(1, 1) те же направления дают концы (3, 1) и (1, 4); сумма снова класс (2, 3). (Рис. L-4a.)

Проверка корректности (из записей + доска). Нужно: если [X₁Y₁⟩ ∼ [XY⟩ и [W₁Z₁⟩ ∼ [WZ⟩, то

[[(X, [XY] + λ[WZ])⟩]_∼ = [[(X₁, [X₁Y₁] + λ[W₁Z₁])⟩]_∼.

Параллельный перенос Φ_X^{X₁} — изоморфизм (с лекции 14.09):

Φ_X^{X₁}([XY] + λ[XZ′]) = Φ_X^{X₁}([XY]) + λ Φ_X^{X₁}([XZ′]) = [X₁Y₁] + λ[X₁Z₁′].

Параллелограмм XYPZ″ переносится в X₁Y₁P₁Z₁″ ⇒ [XP⟩ ∼ [X₁P₁⟩. Коммутативность сложения и аксиомы векторного пространства для V проверяются так же, как для привязанных отрезков (из записей: «очевидна / как для Vₙ»).

Своими словами. Можно целиком «перетащить» чертёж в другую точку — класс суммы/растяжения не изменится. Значит операции на классах не зависят от выбора начала. Тогда V — векторное пространство, а (X, Y) ↦ XY задаёт структуру аффинного пространства на Eₙ.

Не-пример корректности (что было бы плохо). Если бы сумма зависела от точки начала (например, «всегда брать конец первого вектора как начало второго» без параллельного переноса), классы смешались бы — свободный вектор перестал бы быть «свободен».

Изоморфизм Ψ : V → Vₙ

Определение. (из записей) Ψ : V → Vₙ,

Ψ([[WZ⟩]_∼) = [XZ′], где [WZ⟩ ∼ [XZ′]

(каждый класс отображаем в привязанный отрезок-представитель с выбранным началом X).

Обратное: Ψ⁻¹([XY]) = [[XY⟩]_∼. Значит Ψ — биекция. Линейность следует из того, что параллельный перенос — изоморфизм, поэтому Ψ — изоморфизм V ≅ Vₙ.

Своими словами. «Свободные» и «привязанные к одной точке» — одна и та же линейная алгебра, только с разной картинкой. На доске те же стрелки обозначали ψ_X : V → V_X.

Пример. В плоскости: класс всех стрелок длины 1 вправо ↔ конкретная стрелка из O в (1, 0). Сложение классов ↔ сложение координат привязанных стрелок.

Линейная комбинация и ЛНЗ

Дальше V — любое векторное пространство над полем K (из записей).

Определение. Пусть u₁, …, uₙ ∈ V, λ₁, …, λₙ ∈ K. Сумма

λ₁ u₁ + … + λₙ uₙ = ∑_{i=1}^n λᵢ uᵢ

называется линейной комбинацией векторов u₁, …, uₙ с коэффициентами λ₁, …, λₙ. Если хотя бы один λᵢ ≠ 0, комбинация нетривиальная.

Своими словами. Берёшь несколько векторов, каждый растягиваешь своим числом и складываешь.

Пример. В ℝ²: 2·(1, 0) + (−1)·(0, 1) = (2, −1). Коэффициенты 2 и −1 — не все нули ⇒ нетривиальная. (Образ базиса и комбинации — рис. L-4b; коэффициенты — числа, не «третья координата».)

Не-пример (письменно). 0·(1, 0) + 0·(0, 1) = (0, 0) — тривиальная комбинация (все коэффициенты нули). Она всегда даёт ноль и ни о чём не говорит.

Определение. Подмножество U ⊂ V линейно независимо (ЛНЗ), если для любых u₁, …, uₙ ∈ U и любых λ₁, …, λₙ ∈ K

∑ λᵢ uᵢ = 0 ⇒ ∀ i λᵢ = 0.

То есть нет нетривиальной линейной комбинации, равной нулю.

Своими словами. Векторы «не дублируют» друг друга: ни один нельзя собрать из остальных. Если сумма с коэффициентами дала ноль — значит, все коэффициенты были нулями.

Пример. В ℝ² векторы e₁ = (1, 0), e₂ = (0, 1) — ЛНЗ: λ₁ e₁ + λ₂ e₂ = (λ₁, λ₂) = 0 ⇒ λ₁ = λ₂ = 0. (Рис. L-4b — они не на одной прямой.)

Не-пример. (1, 0) и (2, 0): второй = 2·первый. 2·(1, 0) + (−1)·(2, 0) = 0 — нетривиальная зависимость. (Рис. L-4c.) Тот же тип зависимости: (1, 0), (2, 0), (0, 1) тоже не ЛНЗ.

Порождающий набор и базис

Определение. W ⊂ V — порождающий набор, если ∀ v ∈ V существуют n ∈ ℕ, векторы u₁, …, uₙ ∈ W и скаляры λ₁, …, λₙ ∈ K такие, что

v = ∑ λᵢ uᵢ.

Своими словами. Из «кирпичей» W можно сложить любой вектор пространства.

Пример. {(1, 0), (0, 1), (1, 1)} порождает ℝ² (уже первых двух хватает). Не-пример. {(1, 0)} не порождает ℝ²: вектор (0, 1) из одного горизонтального не собрать.

Определение. Порождающий набор W ⊂ V называется базисом, если представление любого v через элементы W единственно:

∀ v ∈ V ∃! n ∈ ℕ, ∃! u₁, …, uₙ ∈ W, ∃! λ₁, …, λₙ ∈ K: v = ∑ λᵢ uᵢ.

Своими словами. Базис — «ровно нужный набор осей»: хватает породить всё, и координаты при этом однозначны.

Пример. Стандартный базис ℝ²: {(1, 0), (0, 1)}. У (3, −2) ровно одно разложение: 3·(1, 0) + (−2)·(0, 1). (Рис. L-4b.)

Теорема (базис Гамеля). (из записей) В любом векторном пространстве существует базис (базис Гамеля). Без доказательства на лекции; идея доказательства опирается на лемму Цорна (помечено в записях).

Дополнено (осторожность). Базис Гамеля для ℝ как пространства над ℚ — «дикий» объект: его нельзя явно выписать, существование неконструктивно. Для курса важно само утверждение «базис есть» и следствия ниже; дальше обычно работают с конечномерными пространствами.

Конечномерность и dim V

Определение. (из записей) V конечномерно, если у него есть базис конечной мощности. Дальше на курсе рассматривают в основном такие.

Предложение №1. (из записей) Если W и W′ — базисы V, то |W′| = |W|. Это общее число обозначают dim V (размерность).

Своими словами. Сколько «осей» ни выбирай в качестве базиса — их всегда одинаково много. Это число и есть размерность.

Пример. dim ℝⁿ = n. dim {0} = 0 (базис — пустой набор).

Предложение №2. (из записей; равносильность — упражнение на лекции) Для W ⊂ V равносильны:

  1. W — базис;
  2. W — максимальный ЛНЗ набор в V (нельзя добавить вектор, не потеряв ЛНЗ);
  3. W — минимальный порождающий набор (нельзя выкинуть вектор, не потеряв порождение);
  4. W — ЛНЗ и порождающий одновременно.

Пример к (2)/(3). В ℝ² набор {(1, 0)} ЛНЗ, но не максимален: можно добавить (0, 1). Набор {(1, 0), (0, 1), (1, 1)} порождает, но не минимален: (1, 1) лишний.

Аддитивные, но не однородные функции

Зачем это на лекции. (из записей) Из существования базиса в любом пространстве следует, что бывают функции f с

f(a + b) = f(a) + f(b),

но не обязательно f(λ a) = λ f(a) для всех скаляров λ. То есть аддитивность ≠ линейность.

Шаг 1. Из аддитивности следует ℚ-однородность. (из записей) Для n ∈ ℕ: f(n x) = f(x + … + x) = n f(x). Отсюда f(x) = f(n · (x/n)) = n f(x/n) ⇒ f(x/n) = (1/n) f(x). При x = y = 0: f(0) = f(0) + f(0) ⇒ f(0) = 0. При y = −x: f(0) = f(x) + f(−x) ⇒ f(−x) = −f(x). Собирая: ∀ a ∈ ℚ, ∀ x f(a x) = a f(x).

Своими словами. Если функция только «уважает сложение», для рациональных множителей однородность всё равно вылезает сама. Беда начинается на иррациональных коэффициентах.

Шаг 2. Контрпример через базис Гамеля. (из записей; поле уточнено) Рассматриваем ℝ как векторное пространство над ℚ (в записях местами написано «над ℝ» — для конструкции Гамеля нужен именно ℚ: иначе базис одномерен и трюк не работает). Пусть W ⊂ ℝ — базис Гамеля над ℚ. Зафиксируем w ∈ W и зададим f на базисе:

f(u) = 1, если u = w;  f(u) = 0, если u ∈ W, u ≠ w;

и продолжим по линейности над ℚ: для r = ∑ λᵢ uᵢ (единственное конечное разложение) полагаем f(r) = ∑ λᵢ f(uᵢ). Тогда f(r) равно коэффициенту при w в разложении r.

Возьмём w′ ∈ W, w′ ≠ w. Тогда f(w′) = 0, но λ := w′/w ∈ ℝ \\ ℚ в общем положении, и

f(λ w) = f(w′) = 0,  λ f(w) = λ · 1 = λ ≠ 0,

значит f(λ w) ≠ λ f(w). При этом f аддитивна по построению.

Пример-картинка (не доказательство). Обычная f(x) = 3x и аддитивна, и однородна над ℝ. «Дикая» f из базиса Гамеля аддитивна, на рациональных ведёт себя прилично, а на каких-то иррациональных «ломает» однородность — но явно её не нарисуешь.

Не-пример. f(x) = x² не аддитивна: f(1+1) = 4 ≠ 1+1 = f(1)+f(1). Это другой тип «плохой» функции.
