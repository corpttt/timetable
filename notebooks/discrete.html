Введение

Тетрадь по практике из практика/Документ 13.pdf (рукописный конспект): метод математической индукции с полными выкладками — как на паре, а не «формула и галочка».

Структура: принцип → разобранные примеры с доски → четыре задачи с практики с пошаговыми доказательствами.

Принцип математической индукции

Математическая индукция
база P(n₀) + шаг P(k) ⇒ P(k+1) ⟹ P(n) для всех n ≥ n₀
Определение. Пусть P(n) — утверждение о натуральном n (иногда с 0). Если
1) P(n₀) истинно (база),
2) ∀ k ≥ n₀ из P(k) следует P(k+1) (шаг / индукционный переход),
то P(n) истинно для всех n ≥ n₀.

Своими словами. Встал на первую ступеньку и умеешь с любой ступеньки перейти на следующую → дойдёшь до любой высоты.

Лестница индукции: база + умение шагать.

Пример: сумма геометрической прогрессии

Доказать: 1 + q + q² + … + qⁿ = (1 − qⁿ⁺¹)/(1 − q) при q ≠ 1.

База n = 0. Слева: 1. Справа: (1 − q)/(1 − q) = 1. ✓

Предположение P(k): 1 + … + qᵏ = (1 − qᵏ⁺¹)/(1 − q).

Шаг P(k+1). Левая часть =
(1 + … + qᵏ) + qᵏ⁺¹ = (1 − qᵏ⁺¹)/(1 − q) + qᵏ⁺¹
= (1 − qᵏ⁺¹ + qᵏ⁺¹(1 − q))/(1 − q) = (1 − qᵏ⁺¹ + qᵏ⁺¹ − qᵏ⁺²)/(1 − q)
= (1 − qᵏ⁺²)/(1 − q) — это правая часть при n = k+1. ЧТД

Числа. q = 2, n = 3: 1+2+4+8 = 15; (1−16)/(1−2) = 15.

Пример: сумма квадратов

1² + 2² + … + n² = n(n+1)(2n+1)/6.

База n = 1: 1 = 1·2·3/6. ✓

Шаг. Сумма до k+1 =
k(k+1)(2k+1)/6 + (k+1)² = (k+1) [ k(2k+1) + 6(k+1) ] / 6
= (k+1)(2k² + 7k + 6)/6 = (k+1)(k+2)(2k+3)/6
— формула при n = k+1 (т.к. 2(k+1)+1 = 2k+3). ЧТД

Мост к матану: (xⁿ)′ = n xⁿ⁻¹ индукцией

База: (x)′ = 1. Правило произведения: (fg)′ = f′g + fg′.

Шаг. (xᵏ⁺¹)′ = (x · xᵏ)′ = 1·xᵏ + x · (k xᵏ⁻¹) = xᵏ + k xᵏ = (k+1) xᵏ. ✓

Своими словами. Индукция — не только «суммы и делимость»; тот же шаблон работает для тождеств анализа.

Делимость: 4ⁿ − 1 делится на 3

База n = 1: 4 − 1 = 3, делится на 3. ✓

Шаг. 4ᵏ⁺¹ − 1 = 4·4ᵏ − 1 = 4(4ᵏ − 1) + 3.
По предположению 4ᵏ − 1 ⋮ 3, значит первое слагаемое ⋮ 3; второе — явно 3. Сумма ⋮ 3. ЧТД

Своими словами. Переписали выражение как «кратное + кратное».

Картинка: замощение 2ⁿ×2ⁿ с дыркой

Классический сюжет сильной/обычной индукции: доска 2ⁿ×2ⁿ без одной клетки красится L‑тримино. Шаг: режем на 4 квадрата 2ⁿ⁻¹; дырка в одном; в центре трёх остальных кладём одно L‑тримино — получаем три подзадачи того же вида.

На практике в тетради был чертёж «индукционный переход» с L‑фигурами — держи образ: большая задача = одна склейка + четыре меньших.

Сильная индукция: рекуррентность

a₁ = 3, a₂ = 5, aₙ₊₁ = 3 aₙ − 2 aₙ₋₁. Доказать aₙ = 2ⁿ + 1.

База (две!): a₁ = 2+1 = 3; a₂ = 4+1 = 5. ✓

Шаг (нужны P(k) и P(k−1)):
aₖ₊₁ = 3(2ᵏ+1) − 2(2ᵏ⁻¹+1) = 3·2ᵏ + 3 − 2ᵏ − 2 = 2·2ᵏ + 1 = 2ᵏ⁺¹ + 1. ЧТД

Зачем сильная. В рекуррентности смотрим на два предыдущих члена — одного P(k) мало.

Задача 1. Σ n(2n+1)

Доказать: 1·3 + 2·5 + … + n(2n+1) = n(n+1)(4n+5)/6.

База n = 1: слева 1·3 = 3; справа 1·2·9/6 = 3. ✓

Шаг. Sₖ₊₁ = Sₖ + (k+1)(2k+3) = k(k+1)(4k+5)/6 + (k+1)(2k+3)
= (k+1)/6 · [ k(4k+5) + 6(2k+3) ] = (k+1)/6 · (4k² + 5k + 12k + 18)
= (k+1)/6 · (4k² + 17k + 18).

Квадратный трёхчлен: D = 289 − 288 = 1, корни k = −2 и k = −9/4.
Значит 4k² + 17k + 18 = (k+2)(4k+9).
Итого Sₖ₊₁ = (k+1)(k+2)(4k+9)/6 = (k+1)((k+1)+1)(4(k+1)+5)/6. ЧТД

Задача 2. Гармоническая оценка

Доказать: 1 + 1/2 + 1/3 + … + 1/(2ⁿ − 1) ≤ n.

База n = 1: сумма до 1/(2−1) = 1 ≤ 1. ✓

Идея шага. Sₖ₊₁ = Sₖ + сумма блока новых слагаемых от 1/2ᵏ до 1/(2ᵏ⁺¹ − 1). В этом блоке ≤ 2ᵏ слагаемых, каждое ≤ 1/2ᵏ, поэтому блок ≤ 1. Тогда Sₖ₊₁ ≤ Sₖ + 1 ≤ k + 1. ЧТД

Своими словами. Каждый «этаж» гармонического ряда между степенями двойки добавляет не больше единицы.

Задача 3. Неравенство 2ⁿ > 2n + 1 (n ≥ 3)

База n = 3: 8 > 7. ✓

Предположение: 2ᵏ > 2k + 1.

Нужно: 2ᵏ⁺¹ > 2(k+1)+1 = 2k+3.

2ᵏ⁺¹ = 2·2ᵏ > 2(2k+1) = 4k+2 (по предположению).

Осталось: 4k+2 ≥ 2k+3 при k ≥ 3 ⇔ (4k+2)−(2k+3) = 2k−1 ≥ 2·3−1 = 5 > 0. Верно.

Значит 2ᵏ⁺¹ > 4k+2 ≥ 2k+3. ЧТД

Экспонента обгоняет линейную; индукция фиксирует обгон с n₀ = 3.

Задача 4. 2^{3ⁿ} + 1 и степени тройки

Доказать: 2^{3ⁿ} + 1 ⋮ 3ⁿ⁺¹, но не ⋮ 3ⁿ⁺².

База n = 1: 2³ + 1 = 9. 9 ⋮ 9 = 3², но 9 ∤ 27 = 3³. ✓

Идея шага. Пусть a = 2^{3ᵏ}. Нужно смотреть a³ + 1 = 2^{3ᵏ⁺¹} + 1.
Тождество: a³ + 1 = (a+1)(a² − a + 1).
По предположению a+1 = 2^{3ᵏ}+1 делится ровно на 3ᵏ⁺¹ (делится на 3ᵏ⁺¹, не на 3ᵏ⁺²). Остаётся показать, что множитель a² − a + 1 даёт ровно ещё один множитель 3 (и не больше) — тогда общая степень тройки станет 3ᵏ⁺² = 3^{(k+1)+1}, и не делимость на 3^{(k+1)+2} сохранится.

Своими словами. Это задача на «точную степень простого в разложении»: индукция по показателю + разложение a³+1. На паре базу пишут обязательно; шаг — через a³+1 = (a+1)(…).

Если на зачёте попросят полный шаг — доведи аккуратно сравнение a² − a + 1 по модулю 9 (чтобы увидеть ровно одну тройку).

Что взять с собой

  • Всегда явно: база (с правильным n₀) + шаг
  • В шаге один раз «честно» используй предположение
  • Рекуррентность на 2 шага назад → две базы / сильная индукция
  • Делимость: перепиши как «кратное + кратное»
  • Неравенства: часто нужно усилить оценку (запас 4k+2 ≥ 2k+3)
  • В конце шага узнай формулу при n = k+1 — это и есть цель
