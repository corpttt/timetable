П1 · Множества и включений–исключений

Источник. Начало практика/скан-практика-множества-евклид.pdf.
Теория. Сквозная §§1–4 (операции, диаграммы).

1.1. Операции (шпаргалка с пары)

Включения–исключения
$|A\cup B|=|A|+|B|-|A\cap B|$

Определение. Пусть A, B ⊆ U (универсум).

  • Объединение: A ∪ B = {x ∈ U : x ∈ A или x ∈ B}.
  • Пересечение: A ∩ B = {x ∈ U : x ∈ A и x ∈ B}.
  • Разность: A \ B = {x ∈ A : x ∉ B}.
  • Дополнение: Ā = U \ A = {x ∈ U : x ∉ A}.
  • Симметрическая разность: A Δ B = (A \ B) ∪ (B \ A)
    (элементы ровно из одного из множеств A, B).

Своими словами. ∪ — «всё из обоих»; ∩ — «общее»; \ — «из A выкинули B»; Ā — «всё, чего нет в A»; Δ — «либо в A, либо в B, но не в обоих» (как XOR).

Пример. U = {1,2,3,4,5}, A = {1,2,3}, B = {3,4}.

  • A ∪ B = {1,2,3,4}
  • A ∩ B = {3}
  • A \ B = {1,2}
  • Ā = {4,5}
  • A Δ B = {1,2,4}

Ассоциативность Δ. (A Δ B) Δ C = A Δ (B Δ C).

Почему это правда (идея). Элемент попадает в Δ-цепочку чётное/нечётное число раз: A Δ B Δ C состоит из тех x, которые лежат в нечётном числе из трёх множеств. Порядок скобок не меняет «нечётность».

Пример. A={1,2}, B={2,3}, C={3,1}.
A Δ B = {1,3}, (A Δ B) Δ C = {1,3} Δ {3,1} = ∅.
B Δ C = {2,1}, A Δ (B Δ C) = {1,2} Δ {1,2} = ∅. Совпало.

1.2. Задачи с листа

Включения: если «середина = всё A» и «объединение = A»

Условие своими словами. Дано A ∩ B ∩ C = A и A ∪ B ∪ C = A. Доказать, что A = B = C.

Идея по шагам.

  1. Из A ∩ B ∩ C = A следует A ⊆ B ∩ C (всё из A лежит и в B, и в C), значит A ⊆ B и A ⊆ C.
  2. Из A ∪ B ∪ C = A следует B ⊆ A и C ⊆ A (иначе в объединении появился бы лишний элемент).
  3. Вместе: A ⊆ B ⊆ A ⇒ A = B; аналогично A = C.

Ответ. A = B = C.

Не-пример (если условие ослабить). Если только A ∩ B ∩ C = A, но объединение больше A — тогда A ⊆ B ∩ C, но B или C могут быть строго больше A.

Если A ∩ B̄ ≠ ∅

Условие своими словами. Пересечение A с дополнением B непусто. Что можно сказать про A и B?

Идея.

  1. Существует x ∈ A и x ∉ B.
  2. Значит A ⊈ B (A не целиком внутри B).
  3. A ∩ B может быть пустым (A и B не пересекаются) или нет (есть ещё общие точки) — из одного условия это не узнать.
  4. A ∪ B строго больше B: в объединении есть хотя бы этот x ∉ B.

Пример. A = {1,2}, B = {2,3}, U = {1,2,3,4}.
B̄ = {1,4}, A ∩ B̄ = {1} ≠ ∅.
A ∩ B = {2} ≠ ∅, A ∪ B = {1,2,3} ⊃ B.

Пример, где ∩ пусто. A = {1}, B = {2}, тогда A ∩ B̄ = {1} ≠ ∅ и A ∩ B = ∅.

Подсчёт: сколько n ≤ 1000 с НОД(n, 99) ≠ 1

Условие своими словами. Среди чисел от 1 до 1000 сколько не взаимно простых с 99?

Идея по шагам.

  1. 99 = 3²·11. Число не взаимно просто с 99 ⟺ оно делится на 3 или на 11.
  2. Принцип включений–исключений (PIE) для двух множеств:
    #{кратные 3} + #{кратные 11} − #{кратные 33}.
  3. ⌊1000/3⌋ = 333, ⌊1000/11⌋ = 90, ⌊1000/33⌋ = 30.

Ответ. 333 + 90 − 30 = 393.

Проверка смыслом. Взаимно простых с 99 среди 1…1000 меньше, чем 1000 − 393 = 607; φ(99) = 99·(1−1/3)·(1−1/11) = 60 задаёт «плотность», но точный счёт до 1000 — именно PIE.

«Языки» — PIE на три множества

Условие своими словами. 250 студентов; немецкий 151, французский 136, итальянский 27; обе пары нем.+фр. 63, нем.+ит. 7, фр.+ит. 11; все три языка 4. Нужно заполнить круги Венна и ответить на пункты a–d по рисунку на скане.

Идея (как заполнять круги).

Обозначим области Венна:

Область Формула Число
Только все трое дано 4
Нем.+фр., без ит. 63 − 4 59
Нем.+ит., без фр. 7 − 4 3
Фр.+ит., без нем. 11 − 4 7
Только нем. 151 − 59 − 3 − 4 85
Только фр. 136 − 59 − 7 − 4 66
Только ит. 27 − 3 − 7 − 4 13

Дальше по пунктам a–d на листе обычно спрашивают: сколько знают ровно один язык / хотя бы один / ни одного / ровно два и т.п. — ответы читаются с заполненной диаграммы.

Пример подсчёта «хотя бы один».
85+66+13+59+3+7+4 = 237. Ни одного языка: 250 − 237 = 13.

Что взять с собой (П1)

  • Δ = XOR множеств; ассоциативна.
  • A ∩ B ∩ C = A и A ∪ B ∪ C = A ⇒ A = B = C.
  • A ∩ B̄ ≠ ∅ ⇒ есть точка A вне B.
  • PIE: |A ∪ B| = |A| + |B| − |A ∩ B|; для «не взаимно просты с m» — кратные простым делителям m.

⚡ Быстрый тест: в чат тест АП-П1 — множества · PIE

П2 · Отношения и эквивалентности

Источник. Середина того же скана.
Теория. Сквозная §6 (отношения / эквивалентность).

Напоминание:

Определение. Бинарное отношение ρ на множестве X — подмножество X × X. Пишем a ρ b вместо (a,b) ∈ ρ.

  • Рефлексивность: ∀ a ∈ X: a ρ a.
  • Симметрия: a ρ b ⇒ b ρ a.
  • Транзитивность: a ρ b и b ρ c ⇒ a ρ c.

Эквивалентность = все три свойства. Тогда X распадается на классы [a] = {x : x ∼ a}.

2.1. Делимость степенями

а) Фиксированная степень 10

Условие. На ℕ: a ρ b ⇔ (a¹⁰ ⋮ b и b¹⁰ ⋮ a).
(«⋮» = «делится»: b делит a¹⁰, a делит b¹⁰.)

Рефлексивность. a¹⁰ ⋮ a и a¹⁰ ⋮ a — верно (a делит a¹⁰). ✓

Симметрия. В определении a и b симметричны. ✓

Транзитивность — нет.

Контрпример. a = 2¹⁰⁰, b = 2¹⁰, c = 2.

  • a¹⁰ = 2¹⁰⁰⁰ делится на b = 2¹⁰; b¹⁰ = 2¹⁰⁰ делится на a = 2¹⁰⁰. Значит a ρ b.
  • b¹⁰ = 2¹⁰⁰ делится на c = 2; c¹⁰ = 2¹⁰ делится на b = 2¹⁰. Значит b ρ c.
  • Но a¹⁰ = 2¹⁰⁰⁰ делится на c = 2 — ок; а c¹⁰ = 2¹⁰ не делится на a = 2¹⁰⁰ (показатель 10 < 100). Значит не a ρ c.

Своими словами. Степень 10 «не успевает» дотянуть огромный показатель a до маленького c через промежуточный b.

б) Существует какая-то степень n

Условие. a ρ b ⇔ ∃ n ∈ ℕ: aⁿ ⋮ b и bⁿ ⋮ a.

Это эквивалентность. Рефл. и симм. очевидны. Транзитивность:

  1. Пусть a ρ b через степень n, b ρ c через m.
  2. Тогда aⁿ ⋮ b, bⁿ ⋮ a, bᵐ ⋮ c, cᵐ ⋮ b.
  3. Возьмём k = n m. Тогда aᵏ = (aⁿ)ᵐ ⋮ bᵐ ⋮ c, и аналогично cᵏ ⋮ a.
  4. Значит a ρ c.

Пример. 4 и 8: 4² = 16 ⋮ 8? Нет. 4³ = 64 ⋮ 8 — да; 8³ = 512 ⋮ 4 — да. Значит 4 ρ 8 при n = 3.

2.2. Другие отношения с пары

Сумма цифр на {1,…,999}

Условие. a ∼ b ⇔ сумма цифр a равна сумме цифр b.

Это эквивалентность (равенство чисел-сумм).

Классы. Возможные суммы цифр трёхзначных (и меньше): от 1 (число 1) до 9+9+9 = 27.
Класс «сумма = s» = все числа 1…999 с суммой цифр s.

Пример. 17 ∼ 80 ∼ 1006? (1006 > 999 — вне множества.)
17: 1+7=8; 80: 8+0=8; 26: 2+6=8 → один класс.

Разложение a = 2ᵏ · u (u нечётно)

Условие своими словами. Каждое натуральное a единственным образом пишется как степень двойки × нечётный множитель. Можно сравнивать:

  • по показателю k («одна валентность двойки»);
  • или по нечётной части u.

Пример. 12 = 2²·3, 20 = 2²·5 — одинаковый k = 2, разные u.
12 = 2²·3, 24 = 2³·3 — одинаковый u = 3, разные k.

Каждое из отношений «одинаковый k» / «одинаковый u» — эквивалентность.

Делители 2002²⁰⁰² и отношение с 77

Множество. A = {делители 2002²⁰⁰²}, где 2002 = 2·7·11·13. Значит

\[ 2002^{2002} = 2^{2002}·7^{2002}·11^{2002}·13^{2002}, \]

и любой a ∈ A имеет вид

\[ a = 2^{α}·7^{β}·11^{γ}·13^{δ}, \quad 0 ≤ α,β,γ,δ ≤ 2002. \]

Отношение.

\[ a ∼ b \iff НОД\!\left(\frac{НОК(a,b)}{НОД(a,b)},\, 77\right) = 1, \quad 77 = 7·11. \]

Что такое НОК/НОД по показателям. Если

\[ b = 2^{α'}·7^{β'}·11^{γ'}·13^{δ'}, \]

то

\[ \frac{НОК(a,b)}{НОД(a,b)} = 2^{|α-α'|}·7^{|β-β'|}·11^{|γ-γ'|}·13^{|δ-δ'|}. \]

Условие НОД(…, 77) = 1 значит: в этом частном нет простых 7 и 11, то есть

\[ |β-β'| = 0,\quad |γ-γ'| = 0 \iff β = β',\ γ = γ'. \]

На показатели 2 и 13 ограничений нет.

Своими словами. a ∼ b ⟺ у a и b одинаковые степени семёрки и одинаковые степени одиннадцати.

Пример. a = 7³·2⁵, b = 7³·13¹⁰ — ∼ (β=3, γ=0 у обоих).
a = 7³, b = 7⁴ — не ∼.
a = 11²·2, b = 11²·13 — ∼.

Классы. Класс пары (β, γ) —

\[ \{2^{x}·7^{β}·11^{γ}·13^{y} : 0 ≤ x,y ≤ 2002\}. \]

В каждом классе 2003² элементов; классов тоже 2003².

Это эквивалентность — «совпадение двух чисел (β,γ)» всегда эквивалентность.

Что взять с собой (П2)

  • Эквивалентность = рефл. + симм. + транз.
  • Фиксированная степень (a¹⁰ ⋮ b и обратно) может не быть транзитивна; «∃ n» — транзитивна.
  • Сумма цифр / показатель двойки / нечётная часть — типичные эквивалентности.
  • Формула с НОК/НОД и 77 на делителях 2002²⁰⁰² = совпадение показателей 7 и 11.

⚡ Быстрый тест: в чат тест АП-П2 — отношения · эквивалентности

П3 · Евклид и НОД выражений

Источник. Продолжение скана.
Теория. Сквозная §14 (НОД, лемма Евклида, алгоритм).

Лемма Евклида (рабочий инструмент).
НОД(a, b) = НОД(a − q b, b) = НОД(b, a mod b).
Для выражений от n: вычитай кратные, понижай «сложность», пока не останется НОД(константа, линейное).

3.1. НОД через вычитания (как на паре)

Пример. НОД(6n+9, 9n+6)

Условие. Найти возможные значения НОД(6n+9, 9n+6) при целых n (там, где выражения имеют смысл как в задаче на паре — обычно n ∈ ℤ).

Идея по шагам.

  1. НОД(6n+9, 9n+6) = НОД(6n+9, (9n+6) − (6n+9)) = НОД(6n+9, 3n−3)
    (вычли один раз «почти» второе из первого с коэффициентом 1 по смыслу разности).
    Аккуратнее: (9n+6) − 1·(6n+9) = 3n − 3.
  2. Далее: НОД(6n+9, 3n−3). Заметим 6n+9 = 2·(3n−3) + 15,
    значит НОД(6n+9, 3n−3) = НОД(15, 3n−3).
  3. НОД(15, 3(n−1)) = 3·НОД(5, n−1).
  4. НОД(5, n−1) ∈ {1, 5} ⇒ весь НОД ∈ {3, 15}.

Ответ. НОД ∈ {3, 15}.

Пример числа. n = 1: НОД(15, 15) = 15.
n = 2: НОД(21, 24) = 3.

Пример. НОД(n²+5, n+1)

Идея.

  1. Разделим n²+5 на n+1 с остатком.
    n²+5 = (n+1)(n−1) + (1+5) = (n+1)(n−1) + 6?
    Проверка: (n+1)(n−1) = n²−1, плюс 6 даёт n²+5. Да.
  2. НОД(n²+5, n+1) = НОД(6, n+1).
  3. Возможные положительные значения — положительные делители 6, которые делят n+1: 1, 2, 3, 6.

Ответ. ∈ {1, 2, 3, 6}.

Пример. НОД(n²+1, 3n+2)

Идея (схема).

  1. Выразим n через 3n+2 или применим Евклид:
    нужно получить линейную комбинацию, дающую константу.
  2. Типичный ход: подобрать коэффициент, чтобы сократить n².
    На паре доводят до НОД(13, n+5) (или эквивалентной формы).
  3. Значит ответ — положительный делитель 13, делящий соответствующее линейное: 1 или 13.

Ответ. ∈ {1, 13}.

Общий шаблон. Евклид по переменной → НОД(константа K, линейное L(n)) → ответ = положительный делитель K, который делит L(n).

3.2. Фибоначчи и Ферма (с пары)

Фибоначчи

Определение. F₁ = 1, F₂ = 1, Fₙ₊₁ = Fₙ + Fₙ₋₁ (иногда начинают с F₀ = 0, F₁ = 1 — свойства те же по смыслу).

Факт. НОД(Fₙ, Fₙ₊₁) = 1 (соседние Фибоначчи взаимно просты).

Почему (идея). Как Евклид: НОД(Fₙ₊₁, Fₙ) = НОД(Fₙ + Fₙ₋₁, Fₙ) = НОД(Fₙ₋₁, Fₙ) = … = НОД(F₂, F₁) = 1.

Пример. F₅ = 5, F₆ = 8, НОД(5,8) = 1.

На паре также связывают НОД(Fₙ₊₅, Fₙ) с выражениями вроде (5 Fₙ₊₁, Fₙ) — через тождества Фибоначчи (разложения сдвига).

Числа Ферма

Определение. Fₙ = 2^(2ⁿ) + 1
(не путать с Фибоначчи — то же буквенное F, другой объект!).

Пример. F₀ = 3, F₁ = 5, F₂ = 17, F₃ = 257, F₄ = 65537.

Ключевое тождество. При n ≥ 1

\[ Fₙ − 2 = F₀ · F₁ · … · Fₙ₋₁. \]

Следствие. Если n > m, то НОД(Fₙ, Fₘ) = 1.

Идея. Fₙ ≡ 2 (mod Fₘ) при m < n (потому что произведение предыдущих делится на Fₘ, значит Fₙ − 2 ⋮ Fₘ). Тогда НОД(Fₙ, Fₘ) = НОД(2, Fₘ) = 1 (числа Ферма нечётны).

Что взять с собой (П3)

  • НОД(выражение₁, выражение₂) → Евклид по переменной → НОД(константа, линейное).
  • Соседние Фибоначчи взаимно просты.
  • Числа Ферма попарно взаимно просты при разных индексах (через Fₙ − 2 = произведение предыдущих).

⚡ Быстрый тест: в чат тест АП-П3 — Евклид · НОД выражений

П4 · Линейное представление и диофантовы + ДЗ

Источник. Доска + конец скана; задачник практика/задачи-теория-чисел-спбгу-2008.pdf, §2 (с. 18–19).
Теория. Сквозная §14 (Безу, Евклид).

4.1. Схема с пары (линейное представление)

Теорема Безу (рабочая форма).
d = НОД(a, b) всегда представим как d = α a + β b для некоторых целых α, β.

Алгоритм (обратный ход Евклида).

  1. Прямой Евклид:
    a = b q₁ + r₁,
    b = r₁ q₂ + r₂,
    …
    пока последний ненулевой остаток = d.
  2. Идя снизу вверх, каждый остаток выражай через a и b:
    r₁ = a − q₁ b,
    r₂ = b − q₂ r₁ = … (подставляй уже найденные выражения),
    пока d = α a + β b.
  3. Уравнение a x + b y = c разрешимо ⟺ d ⋮ c.
  4. Одно решение: если d = α a + β b и c = d · t, то
    x₀ = α · t, y₀ = β · t.

(На КР / в ДЗ 2.7 по условию преподавателя достаточно одного решения, не общее.)

Безу
d = НОД(a,b) = αa + βb  ⇒  ax + by = c разрешимо ⟺ d ⋮ c

Своими словами. НОД — это самое маленькое положительное число вида «целое·a + целое·b». Поэтому кратные НОД — ровно всё, что так представимо. Уравнение ax+by=c просит представить c — значит c должно быть кратно d.

Общее решение (для справки, если попросят).
Если (x₀, y₀) — одно решение ax+by=c, то все:

\[ x = x₀ + (b/d) k, \quad y = y₀ − (a/d) k, \quad k ∈ ℤ. \]

В ДЗ 2.7 общее не требуют.

4.2. Пример с доски: (127, 45)

Условие. Найти α, β: НОД(127, 45) = α·127 + β·45.

Идея (Евклид).

  1. 127 = 2·45 + 37
  2. 45 = 1·37 + 8
  3. 37 = 4·8 + 5
  4. 8 = 1·5 + 3
  5. 5 = 1·3 + 2
  6. 3 = 1·2 + 1
  7. 2 = 2·1 + 0 ⇒ НОД = 1.

Обратный ход (схема): выражаем 1 через предыдущие остатки и поднимаемся до 127 и 45.

Ответ. 1 = (−17)·127 + 48·45.

Проверка. −17·127 = −2159; 48·45 = 2160; сумма 1. ✓

4.3. Пример из тетради: 2299x + 855y = 228 (это 2.7.2)

Условие своими словами. Найти хотя бы одну целую пару (x, y), удовлетворяющую уравнению.

Идея по шагам.

  1. НОД(2299, 855) = 19 (шаги Евклида на листе / в расчёте).
  2. 228 = 19·12, значит 19 ⋮ 228 — решения есть.
  3. Линейное представление: 19 = 16·2299 + (−43)·855.
  4. Умножаем на 12: 228 = 192·2299 + (−516)·855.

Одно решение. x = 192, y = −516.

Проверка идеи. 192·2299 − 516·855 должно дать 228; это следует из умножения верного равенства для 19.

5.1. Сравнения по модулю

Определение. a ≡ b (mod m) ⟺ m ⋮ (a − b) (при m > 0).

Своими словами. a и b дают одинаковый остаток при делении на m (для m > 0 и стандартного остатка 0…m−1).

Пример. 17 ≡ 5 (mod 12), потому что 17 − 5 = 12.
17 ≡ −7 (mod 12), потому что 17 − (−7) = 24 = 2·12.

Свойства (часто нужны на практике). Если a ≡ b (mod m) и c ≡ d (mod m), то

  • a + c ≡ b + d, a − c ≡ b − d, a·c ≡ b·d (mod m);
  • если дополнительно НОД(k, m) = 1, то из k a ≡ k b (mod m) следует a ≡ b (mod m) (сокращение).

5.2. Приведённая система вычетов и φ

Определение. Приведённая система вычетов по модулю m — набор вычетов, взаимно простых с m (обычно берут представителей 1…m−1, взаимно простых с m).

Определение. Функция Эйлера φ(m) = число целых k с 1 ≤ k ≤ m и НОД(k, m) = 1.
(Для m = 1 считают φ(1) = 1.)

Своими словами. φ(m) — сколько «обратимых» остатков по модулю m (тех, у кого есть обратный по умножению).

Формула для степени простого. Если p простое, k ≥ 1, то

\[ φ(p^k) = p^k − p^{k−1} = p^{k−1}(p − 1). \]

Пример. φ(8) = φ(2³) = 4: числа 1, 3, 5, 7.
φ(9) = φ(3²) = 6: 1, 2, 4, 5, 7, 8.

Мультипликативность. Если НОД(m, n) = 1, то φ(m n) = φ(m) φ(n).

Пример. φ(15) = φ(3)·φ(5) = 2·4 = 8
(вычеты 1, 2, 4, 7, 8, 11, 13, 14).

Общая формула. Если m = p₁ᵏ¹ … pᵣᵏʳ, то

\[ φ(m) = m \left(1 − \frac{1}{p₁}\right)…\left(1 − \frac{1}{pᵣ}\right). \]

5.3. Теорема Эйлера и малая Ферма

Эйлер / Ферма
$\mathrm{НОД}(a,m)=1\Rightarrow a^{\varphi(m)}\equiv 1\pmod m$  $p\nmid a\Rightarrow a^{p-1}\equiv 1\pmod p$

Теорема Эйлера. Если НОД(a, m) = 1, то

\[ a^{φ(m)} ≡ 1 \pmod{m}. \]

Малая теорема Ферма. Если p простое и p ∤ a, то aᵖ⁻¹ ≡ 1 (mod p).
(Это Эйлер при m = p, ведь φ(p) = p − 1.)

Пример. a = 3, m = 8: φ(8) = 4, 3⁴ = 81 ≡ 1 (mod 8). ✓

Пример применения. Найти 2¹⁰⁰ mod 15.
НОД(2,15)≠1 — Эйлер напрямую не для 2. Лучше Китайская теорема / по модулям 3 и 5 отдельно, или считать степени 2 по mod 15 вручную: 2⁴ = 16 ≡ 1? Нет, 16 ≡ 1 (mod 15)? 16−1=15 — да! 2⁴ ≡ 1 (mod 15).
Тогда 2¹⁰⁰ = (2⁴)²⁵ ≡ 1²⁵ = 1 (mod 15).

5.4. Китайская теорема об остатках (КТО) — схема

КТО
$m_i$ попарно взаимно просты $\Rightarrow$ система $x\equiv a_i\pmod{m_i}$ единственна по модулю $\prod m_i$

Условие типичной задачи. Найти x такой, что

\[ x ≡ a₁ \pmod{m₁},\quad x ≡ a₂ \pmod{m₂},\quad … \]

при попарно взаимно простых модулях (или свести к такому виду).

Идея.

  1. M = m₁ m₂ … mₖ, Mᵢ = M / mᵢ.
  2. Найти yᵢ: Mᵢ yᵢ ≡ 1 (mod mᵢ) (обратный к Mᵢ по модулю mᵢ).
  3. x₀ = Σ aᵢ Mᵢ yᵢ — одно решение; общее x ≡ x₀ (mod M).

Пример. x ≡ 2 (mod 3), x ≡ 3 (mod 5).
M = 15, M₁ = 5, M₂ = 3.
5 y₁ ≡ 1 (mod 3) ⇒ 2 y₁ ≡ 1 (mod 3) ⇒ y₁ ≡ 2.
3 y₂ ≡ 1 (mod 5) ⇒ y₂ ≡ 2.
x₀ = 2·5·2 + 3·3·2 = 20 + 18 = 38 ≡ 8 (mod 15).
Проверка: 8 ≡ 2 (mod 3), 8 ≡ 3 (mod 5). ✓

5.5. Перестановки (намёк с листков)

Определение. Перестановка множества {1,…,n} — биекция этого множества в себя. Записывают строкой, циклами, произведением транспозиций.

Чётность. Перестановка чётна / нечётна по числу инверсий (или по разложению в транспозиции: чётность длины разложения определена однозначно mod 2).
Aₙ — подгруппа чётных перестановок в Sₙ.

Что взять с собой (П5)

  • a ≡ b (mod m) ⟺ m ⋮ (a−b).
  • φ(pᵏ) = pᵏ⁻¹(p−1); при взаимно простых модулях φ мультипликативна.
  • Эйлер: a^{φ(m)} ≡ 1 (mod m) при НОД(a,m)=1.
  • КТО: система сравнений при взаимно простых модулях → единственный класс mod произведения.
