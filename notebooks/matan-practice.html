П1 · Индукция, Бернулли, бином

Источник. практика/документ-17-индукция-бином.pdf.
Теория рядом. Сквозная §16.1 (индукция), §17.2 (Бернулли). Бином понадобится в П3 при оценке n/aⁿ.

1.1. Принцип математической индукции

Схема. Есть высказывания P₁, P₂, … Нужно доказать все Pₙ.

  1. База: P₁ верно.
  2. Переход: из Pₙ следует Pₙ₊₁.

Тогда Pₙ верно для всех n ∈ ℕ.

Своими словами. Упала первая костяшка (база), и каждая роняет следующую (переход) — падает весь ряд.

Сильная индукция (вторая форма с листа).
1. P₁ верно.
2. Из P₁, …, Pₙ следует Pₙ₊₁.

Связь с множествами (как на листе). Если A ⊆ ℕ, 1 ∈ A (или наименьший элемент), и n ∈ A ⇒ n+1 ∈ A, то A = ℕ. Это же «домино», только языком множеств.

Пример. Доказать 1 + 2 + … + n = n(n+1)/2.
База n = 1: 1 = 1·2/2.
Переход: сумма до k+1 = k(k+1)/2 + (k+1) = (k+1)(k+2)/2.

1.2. Задача. Неравенство Бернулли

Условие. Доказать: (1+x)ⁿ ≥ 1 + nx при n ∈ ℕ, x ≥ −1.

Идея (индукция, как в листке).

  1. База n = 1: 1+x ≥ 1+x — верно.
  2. Пусть (1+x)ⁿ ≥ 1 + nx. Умножаем обе части на (1+x) ≥ 0 (здесь нужно x ≥ −1):
    (1+x)ⁿ⁺¹ ≥ (1+nx)(1+x) = 1 + x + nx + nx² = 1 + (n+1)x + nx².
  3. nx² ≥ 0 ⇒ (1+x)ⁿ⁺¹ ≥ 1 + (n+1)x.

Ответ. (1+x)ⁿ ≥ 1 + nx (x ≥ −1, n ∈ ℕ). Что и требовалось.

Не-пример. При x < −1 множитель 1+x отрицательный — при умножении неравенство может перевернуться; условие x ≥ −1 обязательно.

1.3. Биномиальные коэффициенты

Определение. C(n, k) = n! / (k! (n−k)!) — биномиальный коэффициент (число сочетаний).

Пример. C(5, 2) = 120 / (2·6) = 10.

1.4. Задача. Бином Ньютона

Условие. Доказать: (a+b)ⁿ = ∑_{k=0}^{n} C(n,k) aᵏ bⁿ⁻ᵏ.

Идея.

  1. База n = 1: (a+b) = C(1,0)a⁰b¹ + C(1,1)a¹b⁰ = b + a.
  2. Переход: (a+b)ⁿ⁺¹ = (a+b)ⁿ · (a+b) = (∑ C(n,k) aᵏ bⁿ⁻ᵏ)·(a+b).
    Раскрываем в две суммы и перегруппировываем по степеням aᵏ b⁽ⁿ⁺¹⁾⁻ᵏ.
  3. Коэффициент при aᵏ b⁽ⁿ⁺¹⁾⁻ᵏ оказывается C(n, k−1) + C(n, k).
  4. Остаётся тождество Паскаля: C(n, k−1) + C(n, k) = C(n+1, k).

1.5. Тождество Паскаля

Условие. Доказать C(n, k−1) + C(n, k) = C(n+1, k).

Идея (как в листке).

  1. Пишем через факториалы:
    n! / ((k−1)! (n−k+1)!) + n! / (k! (n−k)!).
  2. Выносим n! / ((k−1)! (n−k)!): в скобках остаётся 1/(n−k+1) + 1/k = (k + n − k + 1)/(k(n−k+1)) = (n+1)/(k(n−k+1)).
  3. Получаем (n+1)! / (k! (n+1−k)!) = C(n+1, k).

Ответ. C(n, k−1) + C(n, k) = C(n+1, k).

Своими словами. Соседние числа в строке треугольника Паскаля в сумме дают число под ними в следующей строке — поэтому бином «наследуется» при умножении на (a+b).

1.6. ДЗ · Демидович №1–10 (§1, с. 8–9)

№ Условие своими словами

2 1² + 2² + … + n² = n(n+1)(2n+1)/6

П2 · ε–N и простейшие пределы

Источник. Фото доски и тетради в практика/документ-16-29.09.pdf (листы с определениями и 1/n).
Теория рядом. Сквозная: §§9–10 (предел последовательности, свойства), §13 (±∞).

2.1. Последовательность и предел (определения с доски)

Определение. Последовательность — отображение f: ℕ → ℝ, aₙ = f(n).

Определение (предел). limₙ→∞ aₙ = a означает:

∀ ε > 0 ∃ N ∈ ℕ: ∀ n > N ⇒ |aₙ − a| < ε.

Своими словами. Какую бы узкую «трубку» ширины 2ε вокруг a ни взять, начиная с номера N весь хвост последовательности лежит внутри этой трубки.

Пример. aₙ = 1/n, a = 0. Для ε = 0,1 нужно |1/n| < 0,1 ⇒ n > 10. Подойдёт N = 10: при n > 10 условие выполнено.

2.2. Бесконечные пределы

Определение. aₙ → +∞, если ∀ M > 0 ∃ N: ∀ n > N ⇒ aₙ > M.
aₙ → −∞, если ∀ M > 0 ∃ N: ∀ n > N ⇒ aₙ < −M.
|aₙ| → +∞ (бесконечно большая), если ∀ M > 0 ∃ N: ∀ n > N ⇒ |aₙ| > M.

Своими словами. +∞ — хвост выше любой положительной планки; −∞ — ниже любой отрицательной; «модуль в ∞» — планка по модулю, знак может скакать.

Пример. aₙ = n → +∞; aₙ = −n² → −∞; aₙ = (−1)ⁿ·n — бесконечно большая, но не стремится ни к +∞, ни к −∞.

2.3. Задача. Доказать 1/n → 0

Условие своими словами. Показать по определению, что предел последовательности 1, 1/2, 1/3, … равен 0.

Идея по шагам.

  1. Фиксируем ε > 0. Нужно |1/n − 0| < ε, то есть 1/n < ε ⇒ n > 1/ε.
  2. Берём N = ⌊1/ε⌋ + 1. Тогда N > 1/ε.
  3. Для любого n > N имеем n > 1/ε ⇒ 1/n < ε.

Ответ. lim 1/n = 0; N = ⌊1/ε⌋ + 1 работает для любого ε > 0.

2.4. Задача. 1/n^α → 0 при α ≥ 1

Условие. Показать, что при α ≥ 1 последовательность 1/n^α стремится к 0.

Идея.

  1. При α = 1 это уже разобрано.
  2. При α > 1: 0 ≤ 1/n^α ≤ 1/n (потому что n^α ≥ n).
  3. Крайние члены → 0 ⇒ по теореме о двух милиционерах середина тоже → 0.
  4. Следствие: a/n^α → a·0 = 0 для любой константы a.

Ответ. 1/n^α → 0 (α ≥ 1); a/n^α → 0.

2.5. Задача. (−1)ⁿ не имеет предела

Условие. Показать, что aₙ = (−1)ⁿ не стремится ни к какому конечному a.

Идея (от противного, как на доске).

  1. Предположим aₙ → a. Тогда для малого ε (например ε = 1) хвост должен лежать в (a − 1, a + 1).
  2. В хвосте есть и члены = 1, и члены = −1. Значит |a − 1| < ε и |a + 1| < ε.
  3. Тогда 2 = |1 − (−1)| ≤ |1 − a| + |a − (−1)| < 2ε. При ε ≤ 1 получаем 2 < 2 — противоречие.

Ответ. Предела нет (последовательность «прыгает» между −1 и 1).

П3 · Рациональные дроби и сравнение роста

Источник. практика/документ-16-29.09.pdf — разбор дробей многочленов + доказательства n/aⁿ → 0 и logₙ/n → 0; на доске номера 41–45, 46, 49, 50 (ДЗ).
Ориентир по дате. Ядро сравнения роста — пары около 29.09; дроби многочленов шли раньше в той же цепочке.
Опора на П1. В оценке n/aⁿ используют бином Ньютона (и идею Бернулли).

3.1. Пример. (n² + n + 1)/(2n² + n + 1)

Условие. Найти limₙ→∞ (n² + n + 1)/(2n² + n + 1).

Идея.

  1. Степени числителя и знаменателя одинаковы (= 2). Делим числитель и знаменатель на n²:
    (1 + 1/n + 1/n²) / (2 + 1/n + 1/n²).
  2. 1/n → 0, 1/n² → 0 ⇒ дробь → (1+0+0)/(2+0+0) = 1/2.

Ответ. 1/2.

3.2. Общее правило (степени k и m)

Пусть aₖ ≠ 0, bₘ ≠ 0:

(aₖ nᵏ + … + a₀) / (bₘ nᵐ + … + b₀).

Делим числитель и знаменатель на nᵐ. Тогда:

Сравнение степеней Предел
k < m 0
k = m aₖ / bₘ
k > m ∞ (знак как у aₖ/bₘ)
Правило
k < m → 0;  k = m → aₖ/bₘ;  k > m → ∞ со знаком aₖ/bₘ

Своими словами. Побеждает старшая степень. Если в знаменателе степень больше — дробь «схлопывается» в 0; если равны — остаются старшие коэффициенты; если числитель «длиннее» — уходит в бесконечность.

Пример. (2n⁴ − 3n³ − n² + 2n − 3) = n⁴(2 − 3/n − 1/n² + 2/n³ − 3/n⁴) — вынесли n⁴, в скобках → 2.

Не-пример (ошибка). Делить на nᵏ, если k < m: знаменатель после деления уйдёт в 0, а нужен контроль старшей степени знаменателя — делят на nᵐ.

3.3. Задача. n / aⁿ → 0 при a > 1

Условие. Доказать: при a > 1 последовательность n/aⁿ стремится к 0.

Идея (как на доске; бином — из П1).

  1. Пишем a = 1 + α, α > 0. Нужно n/(1+α)ⁿ → 0.
  2. Бином Ньютона: (1+α)ⁿ = 1 + nα + C(n,2)α² + … ≥ C(n,2)α² = n(n−1)α²/2 (при n ≥ 2).
  3. Тогда 0 < n/(1+α)ⁿ ≤ n / (n(n−1)α²/2) = 2/((n−1)α²).
  4. Правая часть → 0 ⇒ по милиционерам n/aⁿ → 0.

Ответ. lim n/aⁿ = 0 (a > 1).

Своими словами. Экспонента aⁿ растёт быстрее любой линейной n: даже после деления «хвост» прижимается к нулю.

3.4. Задача. (log_a n) / n → 0 при a > 1

Условие. Доказать, что логарифм растёт медленнее любой линейной функции: log_a n / n → 0.

Идея.

  1. Для каждого n найдём целое k = kₙ так, что aᵏ ≤ n < aᵏ⁺¹ (то есть k = ⌊log_a n⌋).
  2. Тогда k ≤ log_a n < k + 1 и n ≥ aᵏ ⇒
    0 < (log_a n)/n ≤ (k+1)/aᵏ.
  3. Из п. 3.3: (k+1)/aᵏ → 0 при k → ∞. А kₙ → ∞ вместе с n (иначе n ограничена степенью a).
  4. Значит (log_a n)/n → 0.

Ответ. lim (log_a n)/n = 0 (a > 1).

3.5. Усиление. (log_a n) / n^α → 0 при α > 0, a > 1

Условие. То же, но в знаменателе любая положительная степень n^α.

Идея. Аналогично: aᵏ ≤ n^α < aᵏ⁺¹ ⇒ k/α ≤ log_a n < (k+1)/α, и (k+1)/aᵏ → 0.

Ответ. lim (log_a n)/n^α = 0.

П4 · Графики сложных функций

Источник. Тетрадные листы в начале практика/документ-16-29.09.pdf (гипербола + композиция с показательной / логарифмом).
Замечание. На первом листе сверху обрывок доказательства Больцано–Вейерштрасса (теория лекции 24.09) — он уже в сквозной §17; здесь только практическая часть с графиками.

4.1. Внутренняя функция y = (x−1)/(x+2)

Условие. Построить график дробно-линейной y = (x−1)/(x+2) (нужна как внутренняя для показательной).

Идея.

  1. Выделяем целую часть: (x−1)/(x+2) = (x+2−3)/(x+2) = 1 − 3/(x+2).
  2. Это сдвиг гиперболы y = −3/x: влево на 2, вверх на 1.
  3. Вертикальная асимптота x = −2; горизонтальная y = 1.
  4. Пересечения: с Ox при x = 1; с Oy при y = −1/2.

Ответ. Гипербола с асимптотами x = −2 и y = 1; ветви в «квадрантах» относительно асимптот.

4.2. Задача. Z = 3^((x−1)/(x+2))

Условие своими словами. Исследовать композицию: сначала дробь y = (x−1)/(x+2), затем Z = 3ʸ. Найти, какие значения принимает Z на (−∞, −2) и на (−2, +∞).

Идея.

  1. Z = 3ʸ, y = (x−1)/(x+2). Показательная всегда > 0.
  2. На (−∞, −2): y пробегает (1, +∞) ⇒ Z = 3ʸ пробегает (3, +∞).
  3. На (−2, +∞): y пробегает (−∞, 1) ⇒ Z пробегает (0, 3).
  4. При x → −2 слева y → +∞ ⇒ Z → +∞; справа y → −∞ ⇒ Z → 0.
    При x → ±∞ y → 1 ⇒ Z → 3 (горизонтальная асимптота Z = 3, не достигается).

Ответ. На (−∞, −2): Z ∈ (3, +∞); на (−2, +∞): Z ∈ (0, 3); асимптота Z = 3 при |x| → ∞; вертикальный «разрыв» при x = −2.

(Уравнение 3^((x−1)/(x+2)) = 2 на том же листе — сводится к (x−1)/(x+2) = log₃ 2 и решается по графику y или алгебраически.)

4.3. Задача. Z = log_{1/2} |x² − x|

Условие. Построить / описать график Z = log_{1/2} |x² − x|.

Идея.

  1. Внутреннее: u = x² − x = x(x−1). Парабола, корни 0 и 1, вершина x = 1/2, u(1/2) = −1/4.
  2. Модуль y = |u|: отрицательная «ямка» отражается вверх → между 0 и 1 получается горб высотой 1/4 в точке x = 1/2; вне [0,1] парабола как была.
  3. Внешнее: Z = log_{1/2} y. Основание < 1 ⇒ логарифм убывает по y. При y → 0⁺ имеем Z → +∞; при y → +∞ имеем Z → −∞.
  4. Вертикальные асимптоты там, где y = 0: x = 0 и x = 1.
  5. В точке x = 1/2: y = 1/4, log_{1/2}(1/4) = 2 — локальный минимум между асимптотами (Z = 2).

Ответ. Асимптоты x = 0, x = 1; между ними «лощина» с минимумом (1/2, 2); слева от 0 и справа от 1 ветви уходят вниз к −∞ при |x| → ∞.

П5 · Предел функции (документ 15)

Источник. практика/документ-15-практика.pdf.

5.1. Определения (окрестности)

Предельная точка. a ∈ ℝ̄ — предельная точка множества E ⊂ ℝ, если в любой окрестности a есть точка E, отличная от a (эквивалентно: есть последовательность xₙ ∈ E, xₙ ≠ a, xₙ → a).

Стандартные окрестности.
ωₙ(a) = (a − 1/n, a + 1/n);
ωₙ(+∞) = (n, +∞);
ωₙ(−∞) = (−∞, −n).

Определение (общее / «топологическое»). lim_{x→a} f(x) = A (a, A ∈ ℝ̄), если
∀ окрестности G(A) ∃ окрестность ω(a): ∀ x ∈ ω(a) ∩ E, x ≠ a ⇒ f(x) ∈ G(A).

Определение Коши (конечные a, A).
∀ ε > 0 ∃ δ > 0: ∀ x ∈ (a−δ, a+δ) ∩ E, x ≠ a ⇒ |f(x) − A| < ε.

Пример. f(x) = 2x + 1, a = 1, A = 3. |2x+1 − 3| = 2|x−1| < ε при |x−1| < ε/2 — берём δ = ε/2.

5.2. Локальная ограниченность

Утверждение. Если lim_{x→a} f(x) = A ∈ ℝ, то f ограничена в некоторой проколотой окрестности a: ∃ ω̇₀(a), ∃ C > 0: |f(x)| ≤ C на ω̇₀(a) ∩ E.

Идея. Взять ε = 1 ⇒ |f(x) − A| < 1 ⇒ |f(x)| < 1 + |A|. Положить C = 1 + |A|.

5.3. Эквивалентность Коши ⇔ Гейне

Теорема. f(x) → A при x → a ⟺ для любой последовательности xₙ ∈ E, xₙ ≠ a, xₙ → a выполнено f(xₙ) → A.

Коши ⇒ Гейне. Окрестность G(A) даёт окрестность ω(a); хвост xₙ попадает в ω(a) ⇒ f(xₙ) ∈ G(A).

Гейне ⇒ Коши (от противного). Если Коши ложно, есть G₀(A) такая, что в каждой ωₙ(a) найдётся xₙ′ ∈ E ∩ ωₙ(a), xₙ′ ≠ a, с f(xₙ′) ∉ G₀(A). Тогда xₙ′ → a, но f(xₙ′) не → A — противоречие Гейне.

5.4. Единственность предела

Утверждение. Если f(x) → A и f(x) → B при x → a, то A = B.

Идея (через Гейне, как в листке). Берут две последовательности xₙ → a и xₙ′ → a с f(xₙ) → A, f(xₙ′) → B; склеивают t₂ₙ₋₁ = xₙ, t₂ₙ = xₙ′. Тогда tₙ → a ⇒ f(tₙ) имеет предел C; из неравенств треугольника при ε = (1/4)|A−B| получают |A−B| < |A−B| — противоречие, если A ≠ B.

5.5. Арифметика и сравнение

Если f(x) → A, g(x) → B (конечные), то:

  • f + g → A + B;
  • f · g → A · B;
  • если g(x) ≠ 0 и B ≠ 0, то 1/g → 1/B и f/g → A/B.

Если f(x) ≤ g(x) вблизи a (кроме, возможно, самой a) и оба предела конечны, то A ≤ B.

Своими словами. Те же правила, что для последовательностей: предел «проходит» через +, ·, / (где можно) и сохраняет неравенства.

Пример. lim_{x→2} (x² + 1)/(x + 1) = (4+1)/(2+1) = 5/3 — через арифметику, знаменатель → 3 ≠ 0.
