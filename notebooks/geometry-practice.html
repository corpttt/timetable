Декартова система координат

Определение. На плоскости фиксируют начало O и две перпендикулярные оси Ox и Oy. Точке M сопоставляют пару чисел (x, y) — декартовы (прямоугольные) координаты: x — абсцисса, y — ордината.

Своими словами. От начала откладываем «вправо/влево» (x) и «вверх/вниз» (y). От точки опускают перпендикуляры на оси — это проекции, по которым читают x и y.

Пример. Точка M(3, 2): три единицы вправо по Ox, две вверх по Oy. (Рис. П-0.)

Не-пример. Пара (2, 3) — другая точка, не «то же самое, что (3, 2)»: порядок в паре важен.

Деление отрезка в отношении λ

Точки A(x₁, y₁), B(x₂, y₂); точка C(x, y) на отрезке AB.

Определение. Говорят, что C делит отрезок AB в отношении λ, если

λ = |AC| / |CB|,  λ ∈ (0, +∞).

Тогда координаты C:

x = (x₁ + λ·x₂) / (1 + λ) y = (y₁ + λ·y₂) / (1 + λ)

Своими словами. λ показывает, во сколько раз кусок AC длиннее куска CB.

  • λ = 1 → C — середина: x = (x₁ + x₂)/2, y = (y₁ + y₂)/2;
  • λ маленькое → C ближе к A;
  • λ большое → C ближе к B.

Пример. A(0, 0), B(6, 0), λ = 2 (AC вдвое длиннее CB). Тогда AC : CB = 2 : 1, вся AB делится на 3 части, C на расстоянии 4 от A:

x = (0 + 2·6)/(1+2) = 12/3 = 4, y = 0 → C(4, 0).

Пример (как в шпаргалке раньше, другое λ). A(0, 0), B(6, 0), отношение AM : MB = 1 : 2, то есть λ = 1/2:

x = (0 + (1/2)·6)/(1 + 1/2) = 3 / (3/2) = 2 → M(2, 0) ближе к A. (Рис. П-1.)

В записях рядом мелькнуло слово «параметрическая…» — намёк, что ту же точку можно задавать параметром t вдоль прямой; на этой паре главное — формулы с λ.

Полярная система координат

Определение. Фиксируют луч (полярную ось) с началом O (полюс). Точке M сопоставляют:

  • ρ (ро) — расстояние OM (ρ ≥ 0);
  • φ (фи) — угол от полярной оси до луча OM.

Пишут (ρ, φ).

Своими словами. Вместо «вправо–вверх» говорят «на каком расстоянии и под каким углом».

Пример. (ρ, φ) = (2, π/2): два шага «вверх» от полюса, если ось как Ox — точка (0, 2) в декартовых. (Рис. П-2a.)

В углу страницы конспекта ещё набросок «параллельной» системы — для этой темы не разворачивали; можно пока не трогать.

Переход полярные ↔ декартовы

Если полярная ось совпадает с осью Ox, а полюс — с O:

Прямой переход (полярные → декартовы):

x = ρ cos φ y = ρ sin φ

Здесь квадрант «сам» учитывается: cos и sin дают нужные знаки.

Обратный переход (декартовы → полярные):

Полярные ↔ декартовы
ρ = √(x² + y²)  x = ρ cos φ  y = ρ sin φ

Ещё пишут tg φ = y/x — но одной этой формулы мало (нужна четверть / знак), см. ниже.

Своими словами. ρ — длина гипотенузы прямоугольного треугольника с катетами x, y. Угол φ — тот же, что у точки (x, y) в тригонометрии.

Важно про квадранты. Формула tg φ = y/x не отличает, например, угол в I квадранте от угла в III (tg одинаковый). На практике смотрят знаки x и y; на первом занятии достаточно: квадрант проверять глазами.

Квадрант x y пример φ
I > 0 > 0 π/6
II < 0 > 0 5π/6
III < 0 < 0 7π/6
IV > 0 < 0 11π/6

Пример. ρ = 2, φ = π/3.

x = 2·cos(π/3) = 2·(1/2) = 1, y = 2·sin(π/3) = 2·(√3/2) = √3. Точка (1, √3). (Рис. П-2b.)

Не-пример «слепого» угла. Точка (−1, −√3): ρ = 2, tg φ = √3, но это III квадрант → φ = 4π/3, а не π/3.

Задачи на полярные (№ 104–106)

№ 104. Как расположены точки, полярные координаты которых удовлетворяют одному из уравнений (геометрическое место):

Пункт Условие Ответ
a) ρ = 1 окружность с центром в полюсе, радиус 1
b) ρ = 5 окружность, радиус 5
c) ρ = a окружность, радиус a
d) φ = π/6 луч из полюса под углом 30° к полярной оси
e) φ = π/3 луч под 60°
f) φ = π/2 луч под 90° (перпендикуляр к полярной оси)
g) φ = const луч из полюса под этим постоянным углом

Своими словами. Фиксировали расстояние → окружность вокруг полюса. Фиксировали угол → луч из полюса.

№ 105. Построить точку с полярными координатами (1, π/4): из полюса угол 45°, расстояние 1.

№ 106. Правильный шестиугольник; один угол в начале (0, 0), соседний на оси — (a, 0). В записях у вершин полярные вроде (√3 a, π/6), (2a, π/3), …

Формулы для правильного n-угольника:

сумма внутренних углов = π(n − 2) один внутренний угол = ((n − 2)/n)·π

Для n = 6: внутренний угол = (4/6)π = 2π/3 (= 120°).

Откуда появляется ρ = a√3. Две стороны длины a сходятся под 120°. Теорема косинусов:

a² + a² − 2·a·a·cos 120° = 2a² − 2a²·(−1/2) = 2a² + a² = 3a² ⇒ длина диагонали / расстояние = √(3a²) = a√3.

Своими словами. Шестиугольник «сажают» в полярную систему от одной вершины: расстояния до других вершин и углы считают из геометрии правильного многоугольника. (Рис. П-1d.)

Спираль Архимеда

В записях набросок и уравнение:

ρ = c·φ,  c > 0,  часто смотрят 0 ≤ φ < 2π (или дальше — витки).

Своими словами. Чем больше угол, тем больше радиус — линия «раскручивается» от полюса. Это пример кривой, которую удобно писать именно в полярных координатах (в декартовых уравнение тяжелее).

Пример. c = 1, φ = 0 → ρ = 0 (полюс); φ = π → ρ = π; φ = 2π → ρ = 2π — за один оборот радиус вырос на 2π. (Рис. П-1e.)

Прямая: угловой коэффициент

Определение. Уравнение с угловым коэффициентом:

Прямая с угловым коэффициентом
y = kx + b

где k = tg φ, φ — угол наклона прямой к оси Ox; b — ордината пересечения с осью Oy.

Своими словами. k — «наклон»: на сколько поднимаемся, когда x увеличивается на 1. b — где прямая пересекает вертикальную ось.

Пример. y = 2x − 1: наклон 2, пересечение с Oy в точке (0, −1). (Рис. П-2c.)

Не-пример. Вертикальная прямая x = 3 не пишется как y = kx + b: наклон «бесконечный», формула с k не работает — нужен общий вид Ax + By + C = 0 (ниже).

Угол между прямыми; параллельность и перпендикулярность

Для прямых с наклонами k₁ и k₂ угол α между ними:

tg α = |(k₂ − k₁) / (1 + k₁·k₂)|

Условия:

  • параллельны (∥): k₁ = k₂
  • перпендикулярны (⊥): k₁·k₂ = −1

Своими словами. Одинаковый наклон → не пересекаются (или совпадают). Произведение наклонов −1 → «крест» под 90° (классика: если одна растёт как 2, вторая падает как −1/2).

Пример. y = 3x и y = −(1/3)x + 1 — перпендикулярны, потому что 3 · (−1/3) = −1.

Пример из конспекта. № 196: углы между парами прямых (в т.ч. y = 3x и y = −2x + 5 — не перпендикулярны: 3·(−2) = −6 ≠ −1). (Рис. П-2e.)

Формы уравнения прямой

Через точку с данным наклоном

Определение. y − y₀ = k(x − x₀) — прямая через точку (x₀, y₀) с наклоном k.

Шаг 1. По определению наклона для любой другой точки (x, y) на прямой (если x ≠ x₀): k = (y − y₀)/(x − x₀). Шаг 2. Умножили обе части на (x − x₀) — получили уравнение без дроби.

Пример. Через (1, 2) с k = 3: y − 2 = 3(x − 1) ⇒ y = 3x − 1.

Через две точки A(x₁, y₁), B(x₂, y₂)

Определение.

(x − x₁)/(x₂ − x₁) = (y − y₁)/(y₂ − y₁)

Наклон отсюда же: k = (y₂ − y₁)/(x₂ − x₁).

Шаг 1. Наклон между A и произвольной точкой M(x, y) на прямой должен совпадать с наклоном между A и B: (y − y₁)/(x − x₁) = (y₂ − y₁)/(x₂ − x₁). Шаг 2. Переписали «крест-накрест» / в симметричном виде — получили формулу выше. Если x₂ = x₁ — прямая вертикальная: x = x₁ (наклон «бесконечный», через k не пишут).

Пример. A(1, 1), B(3, 5): k = (5−1)/(3−1) = 2, уравнение y − 1 = 2(x − 1).

Общее уравнение прямой

Определение. Уравнение вида

Ax + By + C = 0,

где A, B, C — числа, причём A и B не оба равны нулю, называется общим уравнением прямой на плоскости.

Своими словами. Любая «линейная» комбинация x и y, приравненная к нулю (без x², xy и т.п.), задаёт прямую. Это самый универсальный вид: им описывают и наклонные, и горизонтальные, и вертикальные прямые.

Как связаны y = kx + b и общий вид:

  1. Из y = kx + b перенос: −k·x + 1·y − b = 0 → A = −k, B = 1, C = −b.
  2. Вертикаль x = x₁: 1·x + 0·y − x₁ = 0 — как раз то, чего нет у y = kx + b.
  3. Обратно, если B ≠ 0: y = (−A/B)·x − C/B, то есть k = −A/B, b = −C/B.
  4. Уравнение можно умножить на любое число ≠ 0 — прямая та же (2x − y + 3 = 0 и 4x − 2y + 6 = 0 — одна прямая).

Пример. y = 2x − 1 → −2x + y + 1 = 0 (или 2x − y − 1 = 0). k = −A/B = −2/(−1) = 2 — совпало.

Пример (вертикаль). x = 4 ↔ x − 4 = 0.

Пример из конспекта. AB у △ABC: A(4, 6), B(−4, 6). y = 6 ↔ 0·x + 1·y − 6 = 0 — горизонталь.

В отрезках на осях

Определение. x/a + y/b = 1 — прямая отсекает на Ox отрезок a, на Oy — отрезок b (a ≠ 0, b ≠ 0).

Шаг 1. Прямая проходит через (a, 0) и (0, b). Шаг 2. Подставили в уравнение через две точки / в общее и привели к виду «сумма дробей = 1». Связь с общим: Ax + By + C = 0 при C ≠ 0 делим на −C → a = −C/A, b = −C/B (если A ≠ 0, B ≠ 0).

Пример. x/2 + y/3 = 1 пересекает Ox в (2, 0) и Oy в (0, 3).

(дополнено из Цубербиллера, гл. IV §3–4; на 03.09 успели y = kx + b и формы «через точку / две точки / общее / в отрезках»)

Нормальное уравнение

Определение. (из задачника) В прямоугольной системе нормальное уравнение прямой:

x cos α + y sin α − p = 0,

где p ≥ 0 — длина перпендикуляра из начала O на прямую, α — угол этого перпендикуляра с положительной осью Ox.

Своими словами. Из начала опустили перпендикуляр на прямую: длина p, направление α. Коэффициенты при x и y — как раз cos и sin этого направления, поэтому √(cos²α + sin²α) = 1.

Пример. Прямая x·(3/5) + y·(4/5) − 2 = 0: здесь cos α = 3/5, sin α = 4/5, p = 2. Перпендикуляр из O длины 2; прямая «отстоит» от начала на 2. (Рис. П-2d.)

Как привести Ax + By + C = 0 к нормальному виду. Умножают на нормирующий множитель

μ = ±1 / √(A² + B²),

знак μ выбирают обратным знаку C (чтобы после умножения свободный член стал −p с p ≥ 0). Тогда

cos α = μ A, sin α = μ B, p = −μ C.

Пример. 3x − 4y + 10 = 0. √(9+16) = 5, C = +10 > 0 → берём μ = −1/5:

−(3/5)x + (4/5)y − 2 = 0, или x·(−3/5) + y·(4/5) − 2 = 0.

p = 2 — расстояние от O до прямой.

Расстояние от точки до прямой

Формула. (из задачника) Если прямая уже в нормальном виде, расстояние от M(x₀, y₀) до неё:

δ = |x₀ cos α + y₀ sin α − p|.

Если прямая дана как Ax + By + C = 0 (прямоугольная система):

δ = |A x₀ + B y₀ + C| / √(A² + B²).

Своими словами. Подставил точку в левую часть «общего» уравнения и разделил на «длину» нормали (A, B). Модуль — потому что расстояние неотрицательно.

Пример. Точка M(4, −1), прямая 12x − 5y − 27 = 0:

δ = |12·4 − 5·(−1) − 27| / √(144+25) = |48 + 5 − 27| / 13 = 26/13 = 2.

Не-пример «подставить без модуля и без корня». Число A x₀ + B y₀ + C само по себе — не расстояние: у него есть знак (по какую сторону от прямой точка) и неверный масштаб.

Нормаль в векторном виде (из записей)

Общее Ax + By + C = 0 записывают как

N · r + C = 0,  N = (A, B),

или через точку r₀ на прямой:

N · (r − r₀) = 0,  C = − N · r₀.

Своими словами. N — перпендикуляр к прямой (нормаль). Все радиус-векторы точек прямой «торчат» так, что их разность с r₀ перпендикулярна N. Изменение C при том же N сдвигает прямую параллельно себе.

Угол через нормали (из записей)

Для Ax+By+C=0 и A′x+B′y+C′=0 угол θ между прямыми — тот же, что между нормалями N, N′:

cos θ = (N · N′) / (|N| |N′|),

tg θ = (A B′ − A′ B) / (A A′ + B B′) (в прямоугольной системе).

  • ⊥ ⟺ A A′ + B B′ = 0 (N · N′ = 0);
  • ∥ ⟺ A/A′ = B/B′ (нормали коллинеарны).

№ 271 (из записей). 2x + y − 5 = 0 и 6x − 2y + 7 = 0 (ω = π/2):

№ 274 (из записей). 3x − 2y + 7 = 0 и 6x − 4y − 8 = 0: A/A′ = B/B′ = 1/2 → параллельны (не одна прямая: C не пропорционально).

Пересечение двух прямых и пучок

Две прямые A₁x + B₁y + C₁ = 0 и A₂x + B₂y + C₂ = 0:

  • решаем систему → точка пересечения (если прямые не ∥);
  • если коэффициенты пропорциональны (A₁ : B₁ : C₁ = A₂ : B₂ : C₂) — это одна и та же прямая;
  • если A₁ : B₁ = A₂ : B₂, но C не пропорционально — параллельны, точек пересечения нет.

Пучок прямых через точку пересечения двух данных l₁ = 0 и l₂ = 0 записывают

l₁ + λ l₂ = 0

(при разных λ — разные прямые пучка; отдельно иногда выделяют саму l₂ = 0).

Пример. Прямые x + y − 1 = 0 и x − y = 0 пересекаются в (1/2, 1/2). Уравнение x + y − 1 + λ(x − y) = 0 при любом λ проходит через эту точку.

П3. Окружность (гл. V §1, ≈ №318–370)

(из Цубербиллера; это основной «пропущенный» блок между прямой и эллипсом)

Где по номерам. Задачи на окружность — примерно 318–374. Номер 370 в книге — ещё про окружность (ортогональность к двум данным), не про эллипс. Эллипс — следующий параграф.

Определение и нормальное уравнение

Определение. Окружность — множество точек плоскости на фиксированном расстоянии r (радиус) от фиксированной точки (центр).

Если центр C(a, b), радиус r > 0, то

(x − a)² + (y − b)² = r².  (1)

Окружность
(x − a)² + (y − b)² = r²  ·  x² + y² = r² (центр в O)

Если центр в начале: x² + y² = r².  (2)

Своими словами. Пифагор: катеты |x−a| и |y−b|, гипотенуза r.

Пример. Центр (2, −5), r = 4:

(x − 2)² + (y + 5)² = 16.

Точка (2, −1): (0)² + (4)² = 16 — на окружности. Точка (2, −5) — центр, не на окружности (расстояние 0 ≠ 4). (Рис. П-3a.)

Не-пример. (x − 2)² + (y + 5)² = 0 — только одна точка (центр); (x − 2)² + (y + 5)² = −1 — пустое множество на ℝ².

Общий вид и «узнать окружность»

Раскрыв (1):

x² + y² − 2a x − 2b y + (a² + b² − r²) = 0.

Общее уравнение второй степени Ax² + B y² + C xy + D x + E y + F = 0 задаёт окружность, когда

A = B ≠ 0 и C = 0

(нет xy-члена, коэффициенты при x² и y² одинаковы), и после приведения к виду (1) справа получается положительное r².

Своими словами. «Круглое» уравнение: квадраты x и y с одним коэффициентом, без произведения xy; потом ещё проверить, что радиус вещественный.

Приведение к нормальному виду (выделение квадратов)

Пошагово (как в решении №325 задачника). Дано x² + y² − 8x + 6y + 21 = 0.

  1. Группируем: (x² − 8x) + (y² + 6y) = −21.
  2. Дополняем до квадратов: x² − 8x + 16, y² + 6y + 9 (прибавили 16 + 9 = 25).
  3. Слева: (x − 4)² + (y + 3)²; справа: −21 + 25 = 4.
  4. Итог: (x − 4)² + (y + 3)² = 4 → центр (4, −3), r = 2.

Если коэффициенты при x² и y² равны не 1, а числу k (например 3x² + 3y² − … = 0), сначала делят всё уравнение на k. (Рис. П-3b.)

Правило-шпаргалка при виде x² + y² + D x + E y + F = 0:

a = −D/2, b = −E/2, r² = a² + b² − F

(нужно r² > 0).

Окружность и прямая: секущая, касательная, «мимо»

Совместно решают (1) и Ax + By + C = 0. После исключения одной переменной получается квадратное уравнение. Дискриминант:

  • > 0 — две точки (секущая);
  • = 0 — одна точка (касательная);
  • < 0 — нет действительных точек пересечения.

Касательная к x² + y² = r² в точке (x₁, y₁) на окружности:

x x₁ + y y₁ = r².

Для (x − a)² + (y − b)² = r² в точке (x₁, y₁):

(x − a)(x₁ − a) + (y − b)(y₁ − b) = r².

Пример. Окружность x² + y² = 5, точка (1, −2): 1 + 4 = 5 — на окружности. Касательная: x·1 + y·(−2) = 5, т.е. x − 2y = 5. (Рис. П-3c.)

Что ещё в том же параграфе (кратко, без разжёвывания)

Это уже «надстройка» над базовым (1)–(2); к эллипсу они не обязательны как определение, но по нумерации как раз перед ним.

Видео (одно, на уравнение окружности / кривые 2-го порядка): Линейная алгебра и геометрия · лекция 33 · канонические виды (окружность как частный случай).

П4. Эллипс (гл. V §2, № 375–402)

(Записи: конец Документ 10.pdf (определение, оси, e) и Документ 11.pdf (задачи № 378, 384, 385, 387, 401, 402). Теория — Цубербиллер, введение к гл. V §2, с. 74–75.)

Где остановились. Решены задачи на параметры эллипса, директрисы, эксцентриситет, точку на эллипсе и касательные. Следующие по книге после эллипса: гипербола (§П5, № 433…). Касательные к эллипсу № 403–404 — по желанию.

Определение и каноника

Определение. Эллипс — множество точек, сумма расстояний до двух фокусов постоянна (и равна 2a > расстояние между фокусами).

Каноническое уравнение (оси по координатным, центр в O):

x²/a² + y²/b² = 1,  где b² = a² − c², c > 0 — расстояние от центра до каждого фокуса.

При a = b получается окружность x² + y² = a².

Своими словами. «Вытянутый круг»: вдоль x полуось a, вдоль y — b. Фокусы «разъехались» от центра на ±c по большой оси.

Пример. a = 4, b = 2 ⇒ c = √(16−4) = √12 = 2√3. Уравнение x²/16 + y²/4 = 1. (Рис. П-4; фокусы — рис. П-4b.)

Вершины и оси (из записей)

  • Пересечения с осями — вершины: (±a, 0), (0, ±b).
  • Отрезок между вершинами на большой оси: A₁A₂ = 2a; на малой: B₁B₂ = 2b.
  • Фокусы F₁, F₂: F₁F₂ = 2c.

Эксцентриситет и фокальные радиусы (из записей)

Определение. Эксцентриситет e = c/a (0 ≤ e < 1 для эллипса; у окружности e = 0).

Фокальные радиус-векторы точки M(x₁, y₁) на эллипсе:

r₁ = a − e x₁,  r₂ = a + e x₁,  r₁ + r₂ = 2a.

Своими словами. Из любой точки эллипса «верёвка» до двух фокусов в сумме всегда 2a — как определение. Формулы с e и x₁ — удобный счёт без корней.

Не-пример. r₁ + r₂ = 2a верно только для точек на эллипсе; для внутренней/внешней точки сумма другая.

Пример. Эллипс x²/25 + y²/9 = 1: a = 5, b = 3, c = √(25 − 9) = 4, e = 4/5. Точка M(0; 3) (верхняя вершина): r₁ = 5 − 0,8·0 = 5, r₂ = 5, сумма 10 = 2a. Проверка напрямую: расстояние от (0; 3) до (4; 0) равно √(16 + 9) = 5 ✓.

Как найти фокусы по уравнению

Порядок действий:

  1. Привести уравнение к виду x²/a² + y²/b² = 1: разделить обе части на свободный член.
  2. Посмотреть, какой знаменатель больше. Больший знаменатель стоит при той переменной, вдоль оси которой лежат фокусы. У Цубербиллера почти всегда a > b, то есть фокусы на оси x.
  3. c² = (больший знаменатель) − (меньший знаменатель), c = √(…).
  4. Фокусы: (±c; 0), если больший знаменатель при x; (0; ±c), если при y.

Своими словами. Фокусы всегда «внутри» эллипса на длинной оси, а c = √(a² − b²) — это катет прямоугольного треугольника с гипотенузой a и другим катетом b.

Пример (№ 376). 25x² + 169y² = 4225. Делим на 4225: x²/169 + y²/25 = 1. a = 13, b = 5, c = √(169 − 25) = 12. Оси: 2a = 26, 2b = 10. Фокусы (±12; 0), e = 12/13.

Не-пример. x²/4 + y²/9 = 1: здесь больший знаменатель при y, поэтому фокусы не (±√5; 0), а (0; ±√5). Эллипс вытянут вверх.

Построение циркулем (№ 378). Фокусы можно найти без вычислений. Расстояние от вершины малой оси B(0; b) до фокуса F(c; 0) равно √(b² + c²) = √(b² + a² − b²) = a. Значит, дуга радиуса a с центром в B пересекает большую ось как раз в фокусах. (Рис. П-4c.)

Директрисы

Определение. Директрисы эллипса — две прямые x = −a/e и x = a/e, перпендикулярные большой оси (параллельные малой). Фокус и директриса, лежащие по одну сторону от центра, называются соответствующими.

Свойство. Для любой точки M эллипса отношение расстояния до фокуса к расстоянию до соответствующей директрисы равно e:

r₁ / d₁ = r₂ / d₂ = e.

Своими словами. Директриса лежит снаружи эллипса: так как e < 1, получается a/e > a. Чем эллипс «круглее» (e → 0), тем дальше уходят директрисы.

Пример. x²/25 + y²/9 = 1: e = 4/5, директрисы x = ±5 : (4/5) = ±25/4 = ±6,25. Точка M(5; 0) (правая вершина): r₁ = 5 − 4 = 1, d₁ = 6,25 − 5 = 1,25, r₁/d₁ = 0,8 = e ✓.

Полезная запись: a/e = a/(c/a) = a²/c. (Рис. П-4d.)

Касательная к эллипсу

Формула. Касательная к эллипсу x²/a² + y²/b² = 1 в точке M(x₁; y₁), лежащей на эллипсе:

x·x₁/a² + y·y₁/b² = 1.

Своими словами. Правило «раздвоения»: в уравнении эллипса x² заменяем на x·x₁, y² на y·y₁. Для окружности было то же самое: x·x₁ + y·y₁ = r².

Пример. x²/25 + y²/9 = 1, точка (0; 3): x·0/25 + y·3/9 = 1 ⇒ y = 3. Горизонтальная касательная в верхней вершине, как и ожидалось.

Не-пример. Если точка не лежит на эллипсе, эта формула касательную не даёт. Для внешней точки касательных две, и искать их нужно иначе (№ 402 ниже).

Условие касания прямой Ax + By + C = 0 (Цубербиллер № 411, ответ): A²a² + B²b² = C². Удобно для проверки ответа.

Пример проверки. Прямая x − 2y − 8 = 0 и эллипс x²/16 + y²/12 = 1: 1·16 + 4·12 = 64 = (−8)² ✓. Это касательная.

Везде идея одна: получить соотношение между a и c и поделить, чтобы вышло e = c/a. При необходимости заменяем b² = a² − c².

  • a) Малая ось видна из фокуса под прямым углом. Треугольник B₁FB₂ равнобедренный с прямым углом при F. Высота FO = c равна половине основания OB₁ = b ⇒ b = c. Тогда a² = b² + c² = 2c² ⇒ c/a = 1/√2 ⇒ e = √2/2.
  • b) Расстояние между фокусами равно расстоянию между вершинами малой и большой осей. Вершины (a; 0) и (0; b): расстояние √(a² + b²). Условие 2c = √(a² + b²) ⇒ 4c² = a² + b² = a² + a² − c² ⇒ 5c² = 2a² ⇒ e² = 2/5 ⇒ e = √(2/5) = √10/5.
  • c) Расстояние между директрисами в 4 раза больше расстояния между фокусами. 2a/e = 4·2c ⇒ a/e = 4c ⇒ a²/c = 4c ⇒ a² = 4c² ⇒ e = 1/2.
В пункте (c) в записи «e = 2a/8c» — это не e, а промежуточное равенство 2a/e = 8c. Итог e = 1/2 верный.

П5. Гипербола (гл. V §3, ≈ №433–446)

(Записи: документ-14-практика.pdf. Теория — Цубербиллер, введение к гл. V §3. Условия задач — c:\Users\Ярослав\Desktop\2673_f_41_zadachnik-po-geometrii.pdf.)

Где остановились. После эллипса (§П4) — гипербола: каноника, фокусы, эксцентриситет > 1, асимптоты, директрисы, задачи на составление уравнения и параметры.

Определение и каноника

Определение. Гипербола — множество точек, у которых разность расстояний до двух фокусов постоянна (равна 2a, причём 2a меньше расстояния между фокусами).

Каноническое уравнение (ветки влево–вправо, центр в O):

x²/a² − y²/b² = 1,  где c² = a² + b², c > a — расстояние от центра до каждого фокуса.

Своими словами. У эллипса сумма до фокусов постоянна и «стягивает» овал. У гиперболы постоянна разность: точка «убегает» по двум веткам, а фокусы лежат между ветками по оси x. Знак «минус» в уравнении — как раз про это: x «сильнее», y «слабее».

Пример. a = 4, b = 3 ⇒ c² = 16 + 9 = 25, c = 5. Уравнение x²/16 − y²/9 = 1. Фокусы (±5; 0), вершины (±4; 0). (Рис. П-5.)

Не-пример. x²/16 + y²/9 = 1 — это эллипс (плюс), не гипербола. И формула c² = a² − b² для гиперболы не работает: у гиперболы всегда c² = a² + b².

Эксцентриситет, фокальные радиусы, директрисы

Определение. Эксцентриситет ε = c/a. Для гиперболы всегда ε > 1.

Фокальные радиусы точки M(x, y) на правой/левой ветке (как в записях):

r₁,₂ = |ε x ± a|  (на канонической гиперболе удобны формы r = ±a ± εx в зависимости от ветки и фокуса).

Директрисы: x = ± a/ε.

Свойство. Для точки на гиперболе отношение расстояния до фокуса к расстоянию до соответствующей директрисы равно ε:

r₁ / d₁ = r₂ / d₂ = ε > 1.

Своими словами. У эллипса ε < 1 и директрисы снаружи. У гиперболы ε > 1 ⇒ a/ε < a: директрисы лежат между центром и вершинами. Отношение «фокус / директриса» снова равно ε, но уже больше единицы.

Пример. x²/16 − y²/9 = 1: a = 4, c = 5, ε = 5/4 = 1,25. Директрисы x = ±4/(5/4) = ±16/5 = ±3,2. Вершина (4; 0): расстояние до правого фокуса |5 − 4| = 1, до правой директрисы |4 − 3,2| = 0,8, отношение 1/0,8 = 1,25 = ε ✓.

Асимптоты

Формула. Асимптоты гиперболы x²/a² − y²/b² = 1:

y = (b/a) x  и  y = −(b/a) x.

Своими словами. Это две прямые через начало, к которым ветки «прижимаются» на бесконечности. Их удобно помнить как диагонали прямоугольника со сторонами 2a и 2b.

Пример. Для x²/16 − y²/9 = 1 асимптоты y = ±(3/4)x.

Вертикальная гипербола

Уравнение −x²/a² + y²/b² = 1 (или y²/b² − x²/a² = 1) — ветки вверх–вниз. Тогда роль «главной» полуоси играет b, и ε = c/b, где c² = a² + b².

Пример (из записей, №439). −x²/9 + y²/16 = 1 ⇒ a = 3, b = 4, c = 5, ε = c/b = 5/4 = 1,25.
