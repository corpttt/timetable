# Расписание Б84 — приложение

Веб-приложение (PWA) с интерфейсом в духе GitHub: тёмная тема, карточки, вкладки недель.

При открытии само показывает **текущую** или **ближайшую** пару (часовой пояс Europe/Moscow) и прокручивает к ней.

## Как поставить на телефон (вместо APK)

На ПК нет Android SDK, поэтому готовый `.apk` из этого репозитория не собирается локально. PWA ставится как обычное приложение:

1. Открой страницу приложения в **Chrome** на Android (после публикации на GitHub Pages — см. ниже).
2. Меню ⋮ → **Установить приложение** / **На экран «Домой»**.
3. Иконка «Б84» открывается **без вкладки браузера**.

На Windows: Edge/Chrome → на странице приложения «Установить» — отдельное окно, не вкладка.

Локально для проверки:  
`python -m http.server 8767 --directory расписание/app`  
и открой `http://localhost:8767/`.

## Как обновляется расписание (без переустановки)

Источник данных: [`schedule.json`](schedule.json).

1. Обнови `расписание/Б84.html` (как раньше, через `parse_ods_schedule.py` / `schedule_spa.py`).
2. Выгрузи JSON:

```bash
python scripts/export_schedule_json.py
```

3. Сделай `git push` в GitHub.
4. На телефоне нажми **↻ Обновить** в приложении (или просто открой его онлайн).

Новую версию приложения ставить не нужно — подтягивается только JSON.

## GitHub Pages

В настройках репозитория `corpttt/UCHEBA`:

- Settings → Pages → Source: **Deploy from a branch**
- Branch: `main`, folder: `/ (root)` или docs — удобнее задеплоить папку `расписание/app`.

Вариант через Actions уже лежит в `.github/workflows/schedule-pages.yml`: публикует содержимое `расписание/app` на Pages.

После деплоя URL будет вида:

`https://corpttt.github.io/UCHEBA/`

(точный путь смотри в Settings → Pages).

## Про настоящий APK

Когда понадобится файл `.apk` в магазине / для раздачи друзьям — можно обернуть этот же URL через [PWABuilder](https://www.pwabuilder.com/) (вставь URL Pages → Android package). Оболочка редко меняется; расписание по-прежнему с GitHub.
